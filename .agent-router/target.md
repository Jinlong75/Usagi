# 目标：Usagi 3D 桌宠

来源：`usagi3Dpet.md`（用户需求原文）、2026-11-16 用户对平台与分工的回答。

## 最终目标

一只 Usagi（乌萨奇）3D 桌宠：VRM 角色站在桌面上，会眨眼、看鼠标、耳朵随动作晃，点它有表情和叫声，能用 DeepSeek API 聊天；Mac（.dmg）和 Windows（.exe）都能一键安装。同一个 VRM 也能导入 Mate Engine（Windows）使用。

## 已定方案（决定 D1～D6）

- D1 平台：自己做跨平台桌宠程序（Electron + three + @pixiv/three-vrm），不依赖 Mate Engine；Mate Engine 只做 Windows 上的兼容检查（用户自己在 Windows 电脑上试）。
- D2 建模：用户自己在 Tripo 网页上**图生 3D**（以原图为底图改出 T-pose 多视图 → 智能拓扑；不用文生 3D，用户要求完全还原），把 .glb 放到 `Material/tripo/`；我们只出操作指南。
- D3 五官（2026-11-16 用户确认"方案a"）：Tripo 生成**无五官**的身体（只有底色、耳朵内侧粉色、尾巴）；眼睛、嘴、腮红用贴在脸上的薄片 + 表情贴图集，表情用 VRM 的 UV 平移（textureTransformBinds）切换。理由：Tripo 烘进贴图的五官模糊且没法做表情；五官照原作正脸图描线（还原优先），不凭空画。
- D4 Blender：本机 `~/Applications/Blender.app`（5.2.3 LTS），已装 VRM 插件（extensions: vrm）。所有 Blender 步骤写成命令行脚本（`blender -b --python …`），可重复跑、可验收；每一步出预览图供主导看。
- D5 弹簧骨骼：两只耳朵各一串骨骼（3～4 节）做弹簧，头部和身体加碰撞球。
- D8 模型（2026-11-16）：用户自己用 ChatGPT 生成的参考四视图（`Material/tripo/usagi_3d_ref.png`）在 Tripo 生成了 `Material/tripo/usagi_3d.glb`（无贴图、五官为独立雕刻小块、正面朝 +X）。我们自己上平涂色 + MToon 描边；雕刻五官删除改贴片；**腰线保留不平滑**（用户原话"腰线不用平滑，保留"）。
- D9 作息与问候（2026-11-16 用户确认）：桌宠读系统时钟。早 6:00–10:00 问好+天气+问早饭；午 11:30–13:00 问吃饭没；13:00–14:00 午睡打瞌睡（点击吓醒"哈？"，过会儿再睡）；17:30–19:00 问晚饭；22:30 起提醒早睡（每 30 分钟、最多 3 次）；深夜自己睡着。按"当天该时段第一次看到用户在电脑前"触发、每时段一天一次（本机记录）；离开回来另有招呼；全屏时不打扰、设置里有免打扰与各时段时间。气泡**说口癖**（用户原话"气泡说口癖"；格式按主导建议"呀哈！（早上好～早饭吃了什么？）"，口癖后括号带中文意思，叫声照播）；点问话气泡打开聊天接 DeepSeek，当天回答进记忆。天气：**按 IP 自动定位**（用户选），Open-Meteo 免 Key；查不到就不提天气。
- D10 吸附窗口顶端（2026-11-16 用户确认"两种都有"）：拖到别的窗口上沿附近松手就坐上去；闲逛时也会偶尔自己跳上去（低频、可在设置关）。窗口移动跟随，最小化/关闭/被挡住就跳下。系统窗口位置用 koffi 调 Win32 `EnumWindows` / mac `CGWindowListCopyWindowInfo`。排在 016 合入后。
- D11 动作与道具互动（2026-11-16 用户："多加一些动作的互动，比如说乌萨奇可以吃东西，跳绳等与其他物品互动"，参考 dsh-pet-indesktop）：019 出清单后主导选型，道具用 three.js 几何体/小模型，动作程序化。
- D6 目录：原始素材 `Material/`；Blender 脚本 `pipeline/`；中间与最终模型 `assets/`；桌宠程序 `app/`；给用户的操作指南 `docs/guides/`。占位模型 `assets/placeholder/Seed-san.vrm`（VRM Public License 1.0，VirtualCast），只供开发，不打进安装包。

## 里程碑与完成条件

1. M0 模型：用户按指南在 Tripo 生成并放好 glb。
2. M1 网格清理：`pipeline/blender/cleanup_mesh.py` 合并重合点、去碎片、修法线、统一尺寸与原点；出预览图。
3. M2 骨骼与权重：VRM humanoid 骨骼 + 耳朵骨骼，自动权重后修复（耳根、手臂短小处），导出 VRM 1.0。
4. M3 弹簧骨骼与碰撞体。
5. M4 表情：眨眼、开心、生气、悲伤、惊讶、aa/ih/ou/ee/oh 口型。
6. M5 桌宠程序：透明置顶窗口、拖动、点击穿透、待机动作、看鼠标、托盘菜单；DeepSeek 聊天（用户在设置里填 key，本机加密保存）；叫声音效。
7. M6 安装包：Mac .dmg（arm64）一键安装；Windows .exe（NSIS）一键安装。
8. M7 用户走查：Mac 上实际使用；Windows 上试安装包和 Mate Engine 导入。

## 桌宠功能分级（D7，依据 `docs/research/参考桌宠调研.md`，参考 MerZlin/dsh-pet-indesktop 的行为规则与参数，不抄代码）

**首版（MVP）**
- 窗口：透明无边框置顶、窗口只比模型大一圈、逐像素点击穿透（照搬它的判定真值表，并定时对账防"看得见点不到"）、手动鼠标穿透开关、位置记忆与回右下角、mac `setVisibleOnAllWorkspaces`、不周期性抢焦点。
- 行为状态机：掷骰链 待机 30% / 转向 10% / 随机动作 40% / 移动 20%，只排除上一个；朝向由屏幕位置决定（中线 ±7% 滞回），不随机翻转；移动 60–240px、边距 20px；被拖拽/点击接管时作废计划、不瞬移。
- 程序化动作：呼吸、眨眼、看鼠标、走路、弹跳；耳朵弹簧骨骼，拖动时用窗口加速度带动耳朵晃。
- 互动：点击（阈值 5px×缩放、拖后 150ms 抑制幽灵点击、可打断任何动作）→ 3 种反应（开心"呀哈"弹跳挤压 220ms / 惊讶"哈？"耳朵竖 / 喊叫"乌拉"）+ 叫声；拖动时"被拎起"姿态。
- 气泡与自言自语：默认**开**，间隔 20–60 秒、显示 3.2 秒，HTML 覆盖层在头顶；台词是 Usagi 口癖（呀哈、乌拉、哈？、噗噜噜……），点击台词按反应绑定 `{反应id: [台词]}`。
- 叫声：从 `Material/Usagi_Voice.mp4` 切出的短音效，确认点击后才播、拖动不播、音量 0.7。
- AI 对话：DeepSeek（`https://api.deepseek.com`，模型名以 DeepSeek 官方当前文档为准，可改），设置里只填 Key；Key 用 Electron safeStorage 加密（不可用时明说"仅本次有效"）；流式打字机；单会话、原子写盘、退出前等写完；时间感知；常见 HTTP 码转人话（401/402/429/5xx/证书/代理）；测试连接按钮；Usagi 人设 system prompt；聊天状态联动桌宠（思考中气泡、回复前 60 字气泡、表情）。
- 设置页（单页，关闭即保存）、托盘与右键菜单（显示/隐藏、穿透、聊天、设置、退出）、隐藏时停渲染、闲置降帧。

**第二批**：抛掷物理与静止下落（参数照抄 physics.py）、拖文件"吃掉"（不删文件）、边缘探头、缩放与不透明度、锁定位置/SHIFT 拖动、开机自启、免打扰、DeepSeek 余额、看看屏幕、手动记忆（"记住：…"）、报时、待办、全局快捷键、多屏跨屏。

**不做**：多宠、角色切换、Agent 联动、灵动岛、音乐歌词、主动识屏、每日一签/节日、联网搜索、自动更新、弹弓、黄金回旋、多套气泡风格。
