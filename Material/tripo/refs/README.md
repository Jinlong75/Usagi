## 重建

在仓库根目录执行；依赖仅 Pillow，安装在仓库外临时虚拟环境，不进入 git：

```sh
python3 -m venv /tmp/usagi-004-views-venv
/tmp/usagi-004-views-venv/bin/pip install Pillow==13.0.0
/tmp/usagi-004-views-venv/bin/python tools/views/extract_refs.py
```

需要重新挑帧时，可运行 `tools/views/extract_refs.py --scan`；会在本目录生成 `contact_sheets/`，每个 GIF 均匀采样最多 8 帧，另有帧数/尺寸目录 `catalog.json`。这些选帧中间图不随最终资产提交，改动 `selection.json` 后重新截帧即可。

原素材有背景、其他角色和五官，这是原始参考证据；供 Tripo 上传的是 `../views/` 中四张无五官白底图，不要上传本目录原作截图。
