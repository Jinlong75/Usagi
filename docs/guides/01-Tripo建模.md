# Tripo 建模指南：用准备好的四视图生成 Usagi 3D 模型

整个项目里只有这一步需要你操作。T-pose 四视图已经按原作做好、对齐，放在 `Material/tripo/views/`：

| 文件 | 内容 |
|---|---|
| `front.png` | 正面（T-pose，无五官，耳朵内侧粉色） |
| `back.png` | 背面（白色圆尾巴居中） |
| `left.png` | 左侧：相机在 Usagi 左手边，图里 Usagi **面朝右**，尾巴在左 |
| `right.png` | 右侧：相机在 Usagi 右手边，图里 Usagi **面朝左**，尾巴在右 |
| `sheet.png` | 四张并排 + 原作对照（只看，不上传） |

脸上故意没有五官：眼睛、嘴、腮红后面照原作描成贴片，用来做表情。

## 第一步 上传四视图

1. 打开 <https://www.tripo3d.ai>，进入**图生 3D**（Image to 3D），选**多视图**（Multiview / 多视图）上传方式。
2. 按位置上传：正面 ← `front.png`，背面 ← `back.png`，左 ← `left.png`，右 ← `right.png`。
   - 左右要看 Tripo 上传框旁的示意图：如果它的"左"示意的是**面朝右的侧面**，就按上面放；如果示意的是面朝左，就把 `left.png` 和 `right.png` 对调。
   - 拿不准就先按上面放，生成后用第三步的检查判断；放反了的表现是尾巴跑到侧面或前面。

## 第二步 生成设置

- 网格：选**智能拓扑 / 智能网格**（类似 Smart Mesh、Smart Low Poly、四边面拓扑的选项），面数 **1 万～2 万**，可选时选**四边面**。
- 贴图：开启贴图，有高清贴图（HD Texture）就开；**不要 PBR**（金属度、粗糙度）。
- 姿势：有 T-pose / A-pose 选项就选 **T-pose**。
- **不要**用 Tripo 的自动绑骨 / 动画（Auto Rig），骨骼后面自动做。

## 第三步 检查并导出

生成后在预览里转一圈：

- [ ] 尾巴在正后方（不在侧面或前面——否则回第一步对调左右再生成）
- [ ] 两只耳朵完整、没粘在一起、没断
- [ ] 小短手和身体分开，水平伸出
- [ ] 身体是圆团，背部是圆的
- [ ] 脸上没有五官

满意后导出 **GLB**（带贴图），文件改名为 `usagi_tripo.glb`，放到项目的 `Material/tripo/usagi_tripo.glb`。放好后告诉主导即可，后面的清理、骨骼、权重、弹簧骨骼、表情、桌宠程序都会自动完成。

## 常见问题

- **耳朵粘连或断掉**：换个种子或点重新生成；还不行告诉主导，主导会调整四视图里的耳朵间距。
- **尾巴位置不对**：多半是左右放反，对调 `left.png` / `right.png` 再生成。
- **脸上冒出五官**：没关系，清理时会把脸部贴图涂回底色。
- **背面贴图发灰发糊**：重新生成一次；仍不行告诉主导。
