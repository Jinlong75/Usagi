# Tripo 建模指南：用原图做出还原的 Usagi

目标：用 Tripo 的**图生 3D**（不是文生 3D）做出一个 T-pose 的 Usagi 模型，导出 GLB，放到 `Material/tripo/usagi_tripo.glb`，后面的清理、骨骼、表情由脚本接着做。

整条路线都**以原作图片为依据**：参考图 → 在原图基础上改成 T-pose 多视图（图生图，不是文字凭空生成）→ Tripo 多视图生成 3D。每一步都拿原图对照，偏了就重做这一步。

---

## 准备

- Tripo 账号：<https://www.tripo3d.ai>，网页版即可。积分消耗以网页显示为准（多视图 + 智能拓扑 + 高清贴图通常比普通生成贵）。
- 参考图（都在 `Material/`）：

| 用途 | 文件 | 看点 |
|---|---|---|
| 正面全身（主参考） | `160c479d727476546b1c0c003d15b3f5a6628d9b.gif` | 全身入画：耳朵、短手、两只脚、尾巴都看得到 |
| 背面全身 | `dcb251595f98255a81109cfc47bc01ab1942011.gif` | 背面轮廓、白色圆尾巴位置、小短手从侧面伸出 |
| 正脸五官 | `a694b860e187ac78192c5f0e502fad2a1942011.gif`、`2ca57d0da1e611c5284873ecbb0fc8514a9949c6.gif` | 眼睛、嘴、腮红的位置和比例（做表情贴片时用） |
| 耳朵特写 | `7f1ef01d996e7adba46e30f233abd61f1942011.gif` | 耳朵长度、粗细、内侧粉色范围 |

- 截图方法：用「预览」打开 GIF，停在角色姿势最端正、没有动作模糊的一帧，`Cmd+Shift+4` 截下来存成 PNG。
- 角色特征核对表（每一步出图都对照它）：
  - 奶黄色（接近 `#FFF1C1`），深棕色细描边
  - 头和身体几乎连成一个圆团，下半身略宽
  - 头顶两只**细长、直立、略分开**的耳朵，耳长约等于头高，内侧粉色
  - 手很短，只是身体两侧的小突起；脚是两个小圆头
  - 背后一个白色毛绒圆尾巴，在身体下半部中间

## 第一步 把原图改成 T-pose 多视图

### 1.1 为什么要这样做

- **T-pose**（双臂水平向两侧伸直、两腿略分开）：后面绑骨骼时手臂和身体才能分开，否则手臂会和身体粘成一团、动不起来。
- **多视图**（正面 / 左侧 / 背面 / 右侧）：只给一张正面图，Tripo 会自己"猜"背面和侧面，Usagi 的尾巴、耳朵厚度很容易猜错。给齐四个面，还原度最高。
- **全部用原图做底图**：用支持"上传参考图 + 修改"的图生图工具（例如 Tripo 网页自带的多视图生成功能，或者其他支持参考图编辑的 AI 图片工具），**上传原图**让它只改姿势和视角，不改造型。不要只写文字描述让它重新画。

### 1.2 关于脸：要不要五官（需要你拍板）

- **方案 A（我推荐）：四张多视图都不画五官**，脸上只留奶黄底色；耳朵内侧粉色保留。眼睛、嘴、腮红后面直接**照着原图描**成贴在脸上的薄片。好处：
  1. Tripo 会把细线条五官烘焙得模糊、歪斜，自己描反而**更还原**；
  2. 五官是独立的薄片，才能做眨眼、开心、生气、"哈？！"等表情（需求第 6 步）。
- **方案 B：带五官生成**。Tripo 出来的脸可能更像原图第一眼的感觉，但五官和贴图焊死，做表情只能另外再盖一层，效果和还原度都更差。

下面按方案 A 写；你选 B 的话，把下面提示里"去掉五官"那句删掉即可。

### 1.3 操作

1. 先做 **T-pose 正面图**：上传 `160c479d…` 的截图（主参考），加上下面这段修改要求：

   > 保持这个角色的造型、比例、颜色、描边完全不变，只做以下修改：改成正面正视角（相机正对角色、无透视）；双臂水平向两侧伸直（T-pose），两只脚略微分开站直；去掉脸上的眼睛、嘴巴和腮红，脸部只保留奶黄色底色；两只耳朵完整直立，内侧粉色保留；纯白背景，无阴影，无其他物体；全身完整入画，耳朵尖不要被裁切。

   英文版（工具只认英文时用）：

   > Keep this exact character design unchanged — same proportions, colors and thin dark-brown outline. Only change: front orthographic view facing the camera, arms stretched straight out horizontally (T-pose), feet slightly apart, remove the eyes, mouth and blush so the face is plain cream color, both ears fully upright with pink inner color kept, pure white background, no shadow, no other objects, full body in frame with ear tips not cropped.

2. 正面图满意后，**以这张 T-pose 正面图为参考**，再出背面、左侧、右侧三张；背面那张同时上传 `dcb25159…` 的截图作为第二张参考，要求"背面视角，白色圆尾巴位置和这张参考图一致"。
3. 如果 Tripo 网页有"从一张图生成多视图"的功能，优先用它：上传第 1 步的 T-pose 正面图，让它生成其余视角，再逐张检查、不合格的单独重生成。

### 1.4 出图检查（四张都过了再进下一步）

- [ ] 四张图里角色大小、比例一致（耳朵尖到脚底的高度差不多）
- [ ] 耳朵位置、长度、间距四张一致；侧面图能看出耳朵是扁平的
- [ ] 脸上没有五官（方案 A）
- [ ] 手臂水平伸直，没有贴在身上
- [ ] 背面图有白色圆尾巴，位置和原图一致
- [ ] 纯白背景，没有阴影、地面、文字
- [ ] 和原图并排看，颜色、圆团身形还是"那只 Usagi"

## 第二步 Tripo 多视图生成模型

1. 打开 Tripo 网页，进入**图生 3D**（Image to 3D），选择**多视图**上传方式（类似「Multiview / 多视图」的选项），按位置上传 正面 / 左侧 / 背面 / 右侧 四张图。
2. 生成设置：
   - 网格：选**智能拓扑 / 智能网格**（类似「Smart Mesh」「Smart Low Poly」「四边面拓扑」的选项）。面数建议 **1 万～2 万面**；有"四边面 / 三角面"选择时选四边面。
   - 贴图：开启贴图，有"高清贴图 / HD Texture"就开。不需要 PBR（金属度、粗糙度）。
   - 姿势：如果有"T-pose / A-pose"之类的姿势选项，选 **T-pose**。
   - **不要**用 Tripo 自带的自动绑骨 / 动画（Auto Rig）：我们要做的是 VRM 骨骼，后面用脚本自己绑。
3. 生成后在预览里转一圈检查：耳朵完整不粘连、手臂和身体分开、尾巴在背后、脸部干净。不满意就重新生成（可以先换种子 / 重试，不行再回第一步改图）。

## 第三步 导出与放置

1. 导出格式选 **GLB**（带贴图）。有"导出尺寸 / 单位"选项的保持默认即可，脚本会统一缩放。
2. 文件改名为 `usagi_tripo.glb`，放到项目里：`Material/tripo/usagi_tripo.glb`（没有 `tripo` 文件夹就新建）。
3. 把第一步最终用的四张多视图图片放到 `Material/tripo/views/`，文件名用 `front.png`、`left.png`、`back.png`、`right.png`。这些图后面描五官、核对造型都要用。

## 交付检查

- [ ] `Material/tripo/usagi_tripo.glb` 存在
- [ ] `Material/tripo/views/` 下有四张多视图
- [ ] 在 Tripo 预览里是 T-pose，手臂和身体分开
- [ ] 脸上无五官（方案 A）
- [ ] 耳朵完整、没断、没和头粘成一片
- [ ] 面数在 1 万～2 万左右（Tripo 页面通常会显示）

放好后告诉主导。主导会运行清理脚本（合并重合点、删碎片、统一尺寸），出正面 / 侧面 / 背面预览图给你确认，再进入骨骼步骤。

## 常见问题

- **耳朵粘在一起或断掉**：多视图里两只耳朵间距太小或被裁切。回第一步，把耳朵间距调大一点、确保耳朵尖完整入画，再生成。
- **手臂和身体粘在一起**：多视图里手臂没完全水平，或太短被身体挡住。让手臂明显伸出身体轮廓之外（可以略夸张一点，后面能在 Blender 调）。
- **脸上还是出现了五官**：Tripo 会根据风格"脑补"。检查四张图是否都真的没有五官；仍出现的话没关系，告诉主导，清理时把脸部贴图涂成底色。
- **背面贴图糊、颜色发灰**：背面视图图片质量不够或光照不均。重出背面图，要求"纯色平涂、无阴影"。
- **整体变形、不像 Usagi**：回到第一步，对照原图重新检查多视图；图生 3D 的还原度主要取决于输入图。
