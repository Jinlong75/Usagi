## 1. 安装新版

1. 右键右下角托盘里的 Usagi 图标，点"退出"（看不到就点向上的小箭头）。
2. 下载新安装包 `Usagi-0.1.0-win-x64.exe`（下载地址见主导发给你的消息）。
3. 双击安装，直接覆盖旧版，设置、聊天记录和 DeepSeek key 都会保留。出现 SmartScreen 时点"更多信息"→"仍要运行"。装完会自动启动。

## 2. 连续对话不闪退

1. 右键桌宠 → "和乌萨奇聊天"，打开聊天窗口。
2. 依次发送 `1`、`2`、`3`……一直到 `10`，每条等它回复完再发下一条。
3. **应该看到**：10 轮都正常回复，桌宠和托盘图标一直都在。
4. 不管闪没闪退，都请把崩溃日志发回来：按 Win 键 + R，粘贴下面这行，回车，会打开一个文件夹，把里面的 `crash.log` 发给我（如果闪退了，`crash.log.1` 有的话也一起发）。

```
%APPDATA%\usagi-desktop-pet
```

如果闪退了，再告诉我：闪退时你刚发的是第几条、托盘图标还在不在。

## 3. 转头、拖动时手上方不鼓起

1. 鼠标在桌宠左右两侧慢慢移动，让它转头看鼠标。
2. 按住桌宠左右拖动几下再松开。
3. **应该看到**：两只小手上方的身体轮廓一直是平滑的，**没有尖角或鼓包**（对比上次截图 `docs/research/用户反馈-1117/手上方鼓起.png`）。

## 4. 抬手时头不皱缩

1. 连续点桌宠几次（每次间隔 2 秒），点击会随机触发开心、吃惊、喊叫三种反应，其中**喊叫**会把两手举起；也可以等它自己伸懒腰。
2. **应该看到**：手举起来时，头的两侧和下沿保持圆润，**没有凹折或皱缩**（对比 `docs/research/用户反馈-1117/头部皱缩-抬手.png`）。
3. 手举到最高时，手臂下方的身体可能还有一个很小的凹口，告诉我明不明显。

## 5. 手脚会动

1. 等它自己走路（或拖到屏幕另一边让它走回来）。
   **应该看到**：两只脚交替抬起，两只手一上一下交替摆动。
2. 等它闲着时自己跳一跳（右键菜单没有这一项，点桌宠触发的"开心"也会小跳）。
   **应该看到**：跳到最高时两手举起、两腿微收。
3. 右键 → "喂食" → "饭团"。
   **应该看到**：每咬一口，两只手往上抬一下。
4. 说说动作幅度：太小看不出、刚好，还是太夸张？

## 6. 吃西瓜方向

右键 → "喂食" → "西瓜"。

**应该看到**：西瓜片的绿皮弧边在下面，平的红色切面朝上对着嘴，每咬一口切面往下少一截，最后只剩绿皮。

## 7. 吸附坐下已删除

把桌宠拖到记事本窗口的上边沿松手。**应该看到**：它不会坐上去，就停在松手的位置。右键菜单和设置里也不再有"吸附"相关的选项。
