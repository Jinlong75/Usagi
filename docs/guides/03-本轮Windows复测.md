# 本轮 Windows 复测（2026-11-17）

这一轮修了你 11-16 在 Windows 上提的问题（模型形状、图标、卡顿、切换焦点后点不了、表情），还加了作息问候、早安天气、道具、进食和坐到窗口上。下面只列这一轮要你确认的事，按顺序做，结果填在最后的表里发回来。

`docs/guides/02-安装与使用.md` 里旧的"Windows 复测清单"和"坐到其他窗口上"清单仍然有效，想细测可以照它；本文件是精简版。

## 1. 安装与图标

1. 下载安装包：https://github.com/Jinlong75/Usagi/releases/tag/v0.1.0-test2（私有仓库 Release，文件名 `Usagi-0.1.0-win-x64.exe`）。
2. 如果装过旧版：右键托盘里的 Usagi 图标点"退出"。新安装包直接覆盖安装，设置和聊天记录会保留。
3. 双击安装包。出现 SmartScreen 时点"更多信息"→"仍要运行"。装完会自动启动。
4. 看三处图标：桌面快捷方式、开始菜单、右下角托盘（看不到就点向上的小箭头）。**应该是兔耳头像，不是 Electron 默认图标。**

## 2. 模型形状

看静止站着的桌宠：

- 头和身体之间：腰部往里收一圈（参考 `Material/tripo/usagi_3d_ref.png` 四视图的轮廓）。
- 身体两侧：**不应该有鼓包**。
- 小手：在腰部两侧，**手上方不应有凸起**。

和你上次说的"头和身子之间有线"对照：参考四视图里是轮廓收进去，不是横贯的线。如果你要的是一条画出来的线，告诉我。

## 3. 流畅度

1. 右键桌宠 → 勾选"显示帧率"。左上角出现 FPS 和最长帧间隔（ms）。
2. 依次观察并记下数字（每项至少 10 秒）：静止不动；它自己走路；你在它周围移动鼠标让它转头；点它触发表情。
3. 记下 Windows 显示缩放（例如 150%）和显示器刷新率。
4. 测完取消"显示帧率"。日志在资源管理器地址栏输入 `%APPDATA%\usagi-desktop-pet\logs` 打开，把 `fps.log` 发回来。

## 4. 切换窗口后还能点、能拖

1. 打开记事本，在里面打几个字（让焦点在记事本上）。
2. 直接点一下桌宠：**第一次点击就应触发表情**。
3. 再切到记事本，然后按住桌宠拖动：**应能拖走，松开停住**。
4. 往返做 3 次。

## 5. 表情

1. 点桌宠几次，看不同表情和叫声。
2. 右键 → "喂食" → 依次选"饭团""西瓜""冰淇淋"。
3. 右键 → "玩耍" → 依次选"跳绳""吹泡泡"。
4. 判断：眼睛（带高光的圆眼、眨眼是短横线）、ω 嘴、张嘴时的圆 U 形、腮红斜线，**像不像乌萨奇**；道具有没有穿过脸或身体。说说哪个表情最不像。

## 6. 作息问候与天气

问候按本机时钟、每个时段每天只问一次，所以用改时间的办法马上试：

1. 右键 → "设置…" → 找到"作息"。确认"按作息问候"已勾、"免打扰"没勾。
2. 把"早上开始"改成现在的时间（例如现在 14:05 就填 14:05），"早上结束"改成 30 分钟后（14:35）。点"保存"，**关掉设置窗口**（设置窗口开着时不会问候）。
3. 动一动鼠标（电脑空闲 1 分钟以上不会问候），等最多 30 秒：桌宠头上应出现"呀哈！（早上好～今天……°C。早饭吃了什么？）"一类的气泡，带天气和温度，并有叫声。
4. 在气泡消失前（10 秒内）点它：应打开聊天窗口，里面多了一条乌萨奇的问题。
5. 再打开设置 → "作息"，把"早上"改回 06:00 和 10:00，保存。

如果第 3 步没出现：先确认第 2 步关了设置窗口；今天"早上"时段已经问过就不会再问，可以改用"午饭"或"晚饭"时段同样试。

## 7. 坐到窗口上

1. 打开记事本，把它拖到屏幕中部（上方留出比桌宠还高的空间），不要最大化。
2. 按住桌宠，把它的屁股拖到记事本窗口上沿附近（上下 30 像素内）松手：**应贴着上沿坐下**，小腿在窗口外晃。
3. 拖动记事本窗口：桌宠跟着走。
4. 最小化记事本：桌宠跳回屏幕底部。
5. 再坐上去一次，然后右键桌宠 → "下来"：桌宠跳下来。
6. 打开一个视频网站全屏播放：全屏期间桌宠不应自己跳上窗口，也不应弹作息气泡（这一条能顺手看就看）。
