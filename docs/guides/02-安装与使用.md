# Usagi 安装与使用

程序及模型、叫声素材仅供个人使用，不要分发安装包或素材。文件名带 `-dev`、设置“关于”显示“开发版（占位模型）”的包使用 Seed-san 临时模型，只供开发自测。

## macOS（Apple Silicon：M1、M2、M3 等）

1. 双击 `Usagi-版本-mac-arm64.dmg`（开发包另有 `-dev` 后缀）。
2. 把窗口里的 **Usagi** 拖到“应用程序 / Applications”。复制完成后推出磁盘映像。
3. 在“应用程序”中找到 Usagi，第一次用**右键 → 打开**。程序未用开发者证书签名、未公证，Gatekeeper 可能拦截；按系统提示允许打开。新版系统可能需要在“系统设置 → 隐私与安全性”中点“仍要打开”。只对你自己构建或确认来源的副本这样操作。
4. 如果仍提示损坏或阻止打开，可以在“终端”粘贴下面这行并回车，然后再次打开：

   ```sh
   xattr -dr com.apple.quarantine /Applications/Usagi.app
   ```

启动后到屏幕顶部菜单栏找 Usagi 兔耳头像。程序不在 Dock 中显示；隐藏或开启鼠标穿透时仍可从菜单栏操作。

## Windows（64 位）

1. 双击 `Usagi-版本-win-x64.exe`（开发包另有 `-dev` 后缀），自动安装到当前用户，不需要管理员权限，完成后自动启动。
2. 出现 SmartScreen 时，确认是自己的构建副本后点**更多信息 → 仍要运行**。
3. 桌面和开始菜单会出现快捷方式。程序图标在右下角托盘；看不到时点向上的小箭头。

Windows 安装与卸载行为仍待 Windows 实机验证；在 macOS 上生成 `.exe` 不等于已经完成 Windows 安装测试。

## 第一次填 DeepSeek API Key：照着做

不填写 Key 也能使用桌宠动作和本地叫声；聊天需要自己的 DeepSeek 账户及可用额度。

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com/)，注册或登录自己的账号。
2. 进入“API keys / API 密钥”页面，点“创建 API Key”，给它起一个方便识别的名字。
3. 复制完整 Key。不要发到聊天、截图或给别人；平台通常只在创建时显示完整内容。
4. 点菜单栏/托盘图标，进入**设置 → AI 对话**，把 Key 粘贴到 API Key 输入框。默认 API 地址为 `https://api.deepseek.com`，通常不用改。
5. 点**保存**，再点**测试连接**。显示“连接成功”后，从右键菜单选“和乌萨奇聊天”。

Key 使用系统加密能力保存在本机；若提示“只在本次运行有效”，下次启动需重新填写。具体计费与可用模型以平台显示为准。

| 常见错误 | 处理办法 |
| --- | --- |
| 401 / 认证失败 | 重新复制完整 Key，确认没有漏字符且 Key 未被撤销，保存后再测试。 |
| 402 / 余额不足 | 到开放平台查看余额和账户状态，处理后再试。 |
| 429 / 请求过多 | 停止重复发送，稍等后重试；查看平台限流提示。 |
| 网络失败 / 超时 / 代理错误 | 检查能否打开平台，再检查系统代理、VPN、防火墙。高级设置应填写 API 服务地址，不是网页登录地址。第三方代理需自行确认可信度，Key 会发送到所填地址。 |
| 保存失败 | 按红字检查数据目录权限或磁盘空间，处理后再保存；失败时编辑内容会保留。 |

## 日常操作

- **点它**：左键短按触发随机回应和对应叫声，可以打断当前动作。
- **拖它**：按住角色移动，松开后记住位置。透明背景穿透鼠标，不挡住桌面。
- **右键角色或点托盘**：聊天、设置、隐藏/显示、始终置顶、小/中/大、自言自语、免打扰、鼠标穿透、重新载入模型、退出。
- **聊天**：Enter 发送，Shift+Enter 换行；生成中点“停止”可中断。关聊天窗口只隐藏，记录保存在本机。“清空对话”会再次确认。
- **设置**：调整音量、自言自语间隔和台词、AI 参数和作息。点保存或关闭设置页都会保存并立即生效。
- **点不到角色**：从菜单栏/托盘取消“鼠标穿透”。隐藏后也从这里重新显示。
- **退出**：在菜单栏/托盘或角色右键菜单点“退出”。

## 觉得卡时怎么报数字

从托盘或角色右键菜单勾选**显示帧率**（默认关闭，重启后保留选择）。角色窗口左上角显示最近约 1 秒的平均 **FPS** 和**最长帧间隔（ms）**：FPS 越高通常越流畅，最长帧间隔越大说明偶尔有一帧等得更久。这是实际绘制帧率，不是显示器刷新率；静止约 8 秒后程序会主动降到约 30 FPS 省电，鼠标移动或动作会恢复活动帧率。隐藏窗口期间不采样、不写帧率日志。

开启后，每 10 秒把当时与屏幕相同的一组数字追加到用户数据目录的 `logs/fps.log`。Windows 可在资源管理器地址栏输入 `%APPDATA%\usagi-desktop-pet\logs`；macOS 是 `~/Library/Application Support/usagi-desktop-pet/logs/`。只需提供 `fps.log`，无需分享配置、聊天记录或 Key 文件。测完取消勾选可停止采样和日志。

Windows 复测清单：

1. 打开**显示帧率**，记下程序版本、Windows 版本、显示器刷新率和缩放比例（例如 150% 或 175%）。先静置十几秒，记录 FPS / 最长帧间隔作为对照。
2. 等角色自行走路，观察几秒；再在角色周围移动鼠标让它转头，观察几秒；点角色触发几种表情，各观察几秒。分别记录数字和肉眼的掉帧感，尽量持续开启至少 10 秒以留下日志。
3. 切到记事本或浏览器操作，再移回角色，确认第一次点击能触发表情，按住能拖动，松开能停住；往返重复几次。也可在任务管理器等管理员权限窗口激活后再试。
4. 拖动途中切换到其他窗口，再松开鼠标；移回后确认角色不会继续跟着鼠标走，下一次点击和拖动正常。透明区域仍应能点击下方窗口；主动开启“鼠标穿透”时，角色应保持不可点击，取消后恢复。
5. 把三类动作的 FPS / 最长帧间隔、焦点切换结果和 `fps.log` 发回来。如果日志尚未出现，保持窗口可见并开启诊断超过 10 秒后再找。

## 闪退时怎么找日志

程序会把诊断追加到 `app.getPath('userData')/crash.log`，超过 1 MiB 时保留上一份 `crash.log.1`。重新启动不会清空日志。

当前包的 `package.json.name` 是 `usagi-desktop-pet`，没有 `productName` 字段；打包配置的 `productName: Usagi` 用于安装包与应用显示名称，`extraMetadata` 没有覆盖数据目录名称。本机 Electron 已核实 `app.getName()` 为 `usagi-desktop-pet`，默认日志位置为：

- Windows：`%APPDATA%\usagi-desktop-pet\crash.log`，在资源管理器地址栏输入 `%APPDATA%\usagi-desktop-pet`。
- macOS：`~/Library/Application Support/usagi-desktop-pet/crash.log`，Finder 点“前往 → 前往文件夹”后粘贴目录。

如果某个安装版本将应用内部名称设为 `Usagi`，对应位置是 Windows 的 `%APPDATA%\Usagi\crash.log` 和 macOS 的 `~/Library/Application Support/Usagi/crash.log`。最终以该版本 `app.getPath('userData')` 的实际值为准；每次启动的 `start` 行会记录 `userData` 完整目录。Windows 路径仍需 Windows 安装版实机确认。

闪退后请先复制 `crash.log` 和存在时的 `crash.log.1`，连同程序版本、系统版本及大约几点退出一起提供。无需分享 `config.json`、聊天记录或 Key 文件。

日志里的 `chat` 行只包含累计轮数、耗时和是否出错，不记录消息内容或 API Key。`render-gone` 可定位 pet / bubble / chat / settings 渲染进程，`child-gone` 可定位 GPU 等子进程，`main-exception` / `main-rejection` 记录主进程异常，`quit` 记录托盘退出、所有窗口关闭、启动失败或冒烟退出的来源。`mem` 每 10 分钟记录内存，rss / heapUsed 单位是字节，Electron 各进程 workingSetSize 及合计的单位是 KiB。`fullscreen-disabled` 表示原生窗口读取出错后已停用全屏检测。

原生主进程崩溃、系统强制终止或断电可能没有最后一行；“日志突然停止、没有 quit”不能单独证明具体原因，需要结合 Windows 事件查看器中的故障模块或系统崩溃转储继续确认。

## 数据位置与卸载

当前版本使用以下数据目录（实际以 Electron 用户数据目录为准）：

- macOS：`~/Library/Application Support/usagi-desktop-pet/`。Finder 点“前往 → 前往文件夹”，粘贴路径。
- Windows：`%APPDATA%\usagi-desktop-pet\`。在资源管理器地址栏粘贴路径。

包含 `config.json`（设置）、`chat/session.json`（聊天记录）和 `secrets.json`（加密 Key）。不要分享这些文件；备份或手动删除前先退出程序。

macOS：退出 Usagi，把“应用程序”里的 Usagi 拖到废纸篓。Windows：在“设置 → 应用 → 已安装的应用”中选择 Usagi → 卸载。卸载默认保留用户数据；确认不需要设置和聊天记录后，可自行删除上述数据目录。

程序没有自动更新。更换版本时先退出旧版，再安装新包。

### 作息问候

设置里的“作息”默认开启：早上 06:00–10:00 问早饭、中午 11:30–13:00 问午饭、午睡 13:00–14:00、晚饭 17:30–19:00、22:30/23:00/23:30 催睡、00:00–06:00 睡觉。时间均按本机时钟，可以逐项修改；开始和结束设成相同时间可关闭该时段。午睡和睡觉时暂停自言自语，目前只切换内部状态，身体和眼睛动作待后续完善。

问早饭、午饭、晚饭的气泡可点，显示 10 秒；点下后打开聊天并保留刚才的问题，可以接着回答。没有 DeepSeek Key 时按聊天原有提示去设置填写。普通气泡仍可直接穿透点击。早上默认会说当天的天气和最低～最高温，降水概率达到 50% 会提醒带伞；作息中可取消“早上说天气”。会用网络 IP 向 ip.sb（失败时 geojs.io）查询大致位置，再向 Open-Meteo 查询天气，不需要账号。设置页会显示已缓存的城市；定位缓存 24 小时，天气缓存 1 小时。网络失败或等待超过 3 秒会照常问好，不显示错误；启动后前 5 分钟内的早上时段会预取天气。

托盘、右键菜单和设置页都有“免打扰”，开启后不显示作息气泡、不播放作息叫声，休息状态照常切换。取消“按作息问候”则整个作息停止。桌宠隐藏、拖动、聊天/设置打开、聊天气泡占用或电脑空闲一分钟时会推迟问候，错过时段不会补发；离开半小时后回来会打招呼，两小时内不重复。问候记录保存在本机，重启不会在同一时段重新问一次。

### 全屏检测

普通前台窗口覆盖显示器完整区域时，会暂停作息气泡和自言自语。全屏状态每 2 秒更新，普通最大化（只覆盖工作区）不算全屏。程序只读取其他窗口的边框、层级、可见状态和进程编号，不读取窗口内容或标题，也不要求 macOS 屏幕录制权限。系统接口不可用时在 crash.log 记录一次原因，全屏检测关闭，其他功能照常使用。

Windows 实机复测：用浏览器 F11 / 普通全屏应用检查 2 秒内暂停作息气泡和自言自语；退出全屏后恢复。普通最大化仍允许问候。从安装包启动确认不需要本机编译工具；系统接口不可用时检查日志只有一行关闭原因，拖动、菜单、聊天仍可用。

macOS 实机复测：用绿色按钮进入/退出全屏，检查 2 秒内暂停和恢复作息气泡及自言自语。

旧配置文件中的吸附设置会被忽略，重新保存后不再写入。
