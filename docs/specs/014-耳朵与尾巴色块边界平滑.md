## 目标

现在耳朵内侧的粉色（材质 `EarInner`）边缘是一级一级的锯齿：`pipeline/blender/prep_usagi.py` 的 `assign_regions()` 按**整个三角面的中心**判断归属（`classify_region()` → `ear_inner_region()`），所以色块边界只能沿网格边走。改成**沿理想边界曲线把网格切开**，让粉色区域的边是平滑的长椭圆轮廓，和原作一样。尾巴白色（`Tail`）是同一机制，一起改。然后重跑整条流水线（prep → rig → face），产出新的 `usagi_base.glb`、`usagi_body.vrm`、`usagi.vrm` 与全部预览。

## 范围 / 不做什么

- 做：`prep_usagi.py` 的分区方式；相应测试；`pipeline/README.md` 说明；重出 `assets/model/` 下全部产物（`sh pipeline/build_usagi.sh prep`、`rig`、`face` 依次跑）。
- 不做：改颜色值（`COLORS`、`rig_usagi.py` 的 `MATERIAL_COLORS` 保持不变）；改粉色区域的大小与位置（`ear_inner_region()` 的椭圆参数 60%/0.43/0.51/0.08～0.94 不变，只把它从"判断面"变成"定义切线"）；改骨骼、权重算法、弹簧参数；改五官图集（`pipeline/face/**` 不动，主导刚调过嘴型，见提交 1fe930a）；改 `docs/specs/checks/**`（主导维护，检查不过就停下汇报）；改 `assets/models/**`（带 s，桌宠在用的拷贝，由并行的 013 负责）。
- 做不通就停下汇报，不改清单以外的文件。

- 尾巴：参考图"背面"屁股上的白色圆。

## 要求

1. **切线方法（推荐，可换等价做法但要在汇报里说明）**：对每只耳朵，用现有 `ear_inner_region()` 的同一组几何（`sections` 插值的中心、半宽、`t` 与椭圆项）定义一个**按顶点计算的连续标量** `f(v)`（区域内为负、外为正，零等值线就是现在判断条件的边界）；对两端点 `f` 异号的边，按线性插值在 `f=0` 处切分（bmesh `edge_split`/`bisect` 一类），再把被穿过的面沿新点切开；之后每个面按中心归属上色。效果是边界是一条跟随理想曲线的折线，每段长度不超过原网格边长。尾巴同理（球面距离 `|v-center| - radius*1.15` 一类的连续量，同时保留"只在背面"的条件）。
2. 原来的"只选前侧"条件（`normal.y >= -.25` 就排除）不能再产生锯齿：把它也改成连续量参与，或确认在椭圆边界以内法线条件处处成立（汇报里给出依据：区域内面法线 `y` 的最大值）。
3. 若耳朵处网格太稀导致曲线仍显折角，可只在耳朵内侧区域附近先细分一次再切（写进汇报：细分前后面数）。不对全身细分。
4. 切开后仍是 **1 个连通网格**（009 检查会数连通块），不产生重复点、零面积面（用现有 `cleanup_mesh.clean` 一类清理）；顶点组与 `_USAGI_REGION` 掩码照旧写。
5. 下游照常：`rig` 阶段的耳朵/尾巴权重与区域检查（`rig_usagi.py` 的 `ear_region`/`tail_region` 检查）仍通过；`face` 阶段输出 `usagi.vrm` 与输入 `usagi_body.vrm` 的节点 TRS 与逆绑定矩阵一致（011 的测试已覆盖）。
6. **新增测试**（`pipeline/tests/test_prep_usagi.py` 或新文件）：
   - 合成网格（例如细分平面或圆柱）上跑新的分区函数，断言 `EarInner` 边界边组成闭合环，且环上相邻两段的**转角都小于 35°**（锯齿是 90° 转角）。
   - 对正式产物 `assets/model/usagi_base.glb`（存在时才跑）同样断言：每只耳朵的 `EarInner` 边界是 1 个闭合环、相邻段转角都小于 35°；尾巴边界同样检查。
   - 在汇报 `## 反向实验` 里写一条：把新分区换回"按面中心判断"后，上述正式产物测试会失败（实际跑一次，贴退出码）。
