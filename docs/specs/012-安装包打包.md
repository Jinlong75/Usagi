## 目标

用 electron-builder 给桌宠出两个安装包：macOS Apple Silicon 的 `.dmg`、Windows x64 的 NSIS 一键安装 `.exe`（双击即装、装完自动启动）。打包后的应用能找到 VRM 模型和叫声素材，并能用 `--smoke` 跑通冒烟。写一份给用户的中文安装使用指南。

## 范围 / 不做什么

- 做：electron-builder 配置、打包后的资源路径解析、图标、打包脚本、打包后冒烟、安装指南。
- 不做：代码签名与公证（没有证书）、自动更新、Linux 包、上传发布（**素材有版权，只供个人使用，不发布**）。

## 参照

- 现有程序：`app/`（Electron 45.3.2，`app/src/main/model.ts` 现在按开发模式从仓库根目录解析模型，留有 `TODO(lead): 打包后的模型路径`；`app/src/main/sounds.ts` 同样有 `TODO(lead): 打包后的音效路径`）。
- 参考项目的坑：`docs/research/参考桌宠调研.md` E10（本地能跑、打包后缺资源；VRM、音效必须在打包产物里实测加载）。
- 本机下载 Electron 很慢（全量验收里首次下载约 20 分钟）。审查遗留 R5-1：冒烟入口在首次下载 Electron 时没有超时保护。
- 素材许可：`assets/placeholder/Seed-san.vrm` 是 VRM Public License 1.0，**不得打进正式安装包**；正式包用 `assets/models/usagi.vrm`（Usagi 模型合流后才会出现）。

## 要求

### 1. 资源与路径（`app/src/main/paths.ts`，`model.ts`、`sounds.ts` 改为调用它）
- 打包后：模型从 `process.resourcesPath/models/usagi.vrm`，音效从 `process.resourcesPath/sounds/usagi/`（electron-builder `extraResources` 拷贝）。开发模式保持现有的仓库根目录解析。
- 用户配置里的 `modelPath` 仍优先。
- `extraResources`：`../assets/models/usagi.vrm` → `models/usagi.vrm`；`../assets/sounds/usagi/*.ogg` 与 `manifest.json` → `sounds/usagi/`。
- **占位模型规则**：`assets/models/usagi.vrm` 不存在时，打包脚本自动改用 `assets/placeholder/Seed-san.vrm` 作为 `models/usagi.vrm`，并把产物文件名加 `-dev` 后缀、在应用"关于"里显示`开发版（占位模型）`；存在时出正式包，**正式包里不得包含 Seed-san**（打包脚本检查）。
- 单测覆盖路径解析（开发 / 打包 / 配置优先）。

### 2. electron-builder（`app/electron-builder.yml`）
- `appId: local.usagi.desktoppet`，`productName: Usagi`，版本取 package.json。
- mac：`target: dmg`，`arch: arm64`，`category: public.app-category.entertainment`，`LSUIElement: true`（只在菜单栏，不进程序坞），ad-hoc 签名（`identity: null` 或 `-`，按 electron-builder 当前版本可行的方式），dmg 窗口里有 "拖到 应用程序" 的布局。
- win：`target: nsis`，`arch: x64`；`nsis.oneClick: true`、`perMachine: false`（装到当前用户，不要管理员）、`runAfterFinish: true`、创建桌面与开始菜单快捷方式、卸载时保留用户数据；在 mac 上构建时设置 `signAndEditExecutable: false`（避免需要 Wine 的 rcedit），图标仍尽量设置；如果 electron-builder 在 mac 上出 NSIS 仍需要 Wine，**不要安装 Wine**，在汇报里写明并给出可行方案（例如以后在 Windows 上运行同一个命令），`dist:win` 失败不影响本任务验收但要如实汇报。
- 下载镜像：electron-builder 的 `electronDownload.mirror` 和 `app/.npmrc` 的 `electron_mirror` 设为 `https://npmmirror.com/mirrors/electron/`；注释说明原因（本机直连下载很慢），可用环境变量覆盖。
- 产物输出到 `app/release/`（加进 `.gitignore`）。

### 3. 图标（`app/build/`）
- 从 `Material/tripo/usagi_3d_ref.png` 正面截取 Usagi 头像（含耳朵），做成 1024×1024 透明背景图，生成 `icon.icns`（mac）和 `icon.ico`（Windows，含 16～256 多尺寸），以及托盘用的 `trayTemplate.png`（mac 菜单栏单色模板图 16/32px）与 `tray.png`（Windows）。生成脚本放 `app/scripts/`，可重跑（工具装在仓库外临时环境）。托盘改用新图标（替换 003 留的 `TODO(lead): 换成 Usagi 图标`）。

### 4. 打包脚本（`app/package.json`）
- `dist:mac`、`dist:win`、`dist`（两者都出）。
- 冒烟入口给"首次下载 Electron"加外层超时（审查 R5-1）：整个冒烟命令 10 分钟内没结束就杀掉子进程、打印原因、退出 1。

### 5. 打包后冒烟
- 支持打包后的应用用命令行参数 `--smoke` 运行（与开发模式同一套冒烟逻辑，输出同样的 JSON），用来证明打包后模型、音效、气泡都能加载。

### 6. 安装使用指南（`docs/guides/02-安装与使用.md`，中文，面向普通用户）
- mac：双击 dmg → 拖进"应用程序" → 第一次打开要**右键 → 打开**（未签名，Gatekeeper 拦截），或终端 `xattr -dr com.apple.quarantine /Applications/Usagi.app`；打开后在菜单栏找 Usagi 图标。
- Windows：双击 exe 自动安装并启动；SmartScreen 提示时点"更多信息 → 仍要运行"；托盘在右下角。
- 怎么填 DeepSeek API Key（照参考项目的"小白照抄版"写法：平台地址 platform.deepseek.com、创建 Key、粘到设置、点测试连接）、常见错误（401/402/429/代理）。
- 基本操作：点它、拖它、右键菜单、聊天、设置、退出；数据目录位置；卸载方法。
- 说明"仅个人使用，不要分发"。

## 验收标准

- verify 三条通过。`docs/specs/checks/012-check.sh` 由主导维护：运行 `npm --prefix app run dist:mac`，检查 `app/release/` 下有 `.dmg`；挂载 dmg（`hdiutil attach -nobrowse -readonly`）检查 `Usagi.app` 里有 `Contents/Resources/models/usagi.vrm` 与 `Contents/Resources/sounds/usagi/manifest.json`；把 app 拷到临时目录，运行 `Usagi.app/Contents/MacOS/Usagi --smoke` 检查输出 `"ok":true`；卸载 dmg；把冒烟截图和 dmg 文件名清单复制到门禁产物目录。
- `dist:win` 能在本机产出 `.exe` 更好；不能的话汇报写清原因与替代方案。
- 主导自己装 dmg 试一次。
