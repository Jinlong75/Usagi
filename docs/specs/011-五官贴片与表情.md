## 目标

给 010 产出的 `assets/model/usagi_body.vrm` 加上**照原作画的五官**（眼睛、眉线、嘴、腮红），并做出 VRM 表情：`blink`、`blinkLeft`、`blinkRight`、`happy`、`angry`、`sad`、`relaxed`、`surprised`、`aa`、`ih`、`ou`、`ee`、`oh`、`neutral`。五官是贴在脸上的薄片，表情靠切换表情图集里的格子（VRM 1.0 `textureTransformBinds`，二值切换）。产出最终角色 `assets/model/usagi.vrm`，`sh pipeline/build_usagi.sh face` 一键生成。

## 范围 / 不做什么

- 做：`pipeline/blender/face_usagi.py`、表情图集绘制脚本 `pipeline/face/draw_atlas.py`、`build_usagi.sh face` 阶段、测试、README、产物。
- 不做：改骨骼/权重/弹簧（010 的事，发现问题写 `TODO(lead)`）；替换桌宠程序里的模型（后续合流任务）；修改 `Material/`。

## 参照

- 输入：`assets/model/usagi_body.vrm`（010 产物；脸部区域只受 `Head` 影响）、`assets/model/usagi_landmarks.json`（`face_center`、`face_normal`、`face_radius`）。
- **五官位置**：直接用用户模型上原来雕刻五官的位置（009 删掉的那 7 块）。009 之前的坐标（Blender，正面 +X，高 1.0、原点脚底）：眼 `x 0.241..0.290, y ±(0.064..0.145), z 0.419..0.497`；眉线 `x 0.169..0.212, y ±(0.074..0.216), z 0.513..0.640`；嘴 `x 0.251..0.286, y -0.055..0.050, z 0.303..0.404`。009 把模型绕 Z 转了 -90°（正面改朝 -Y），换算后使用；也可以重新读 `Material/tripo/usagi_3d.glb` 用同样的流程算（推荐，避免手算错）。
- **画风来源**：`Material/tripo/usagi_3d_ref.png` 的正面（用户认可的造型）、原作截帧 `Material/tripo/refs/face.png`、`Material/a694b860e187ac78192c5f0e502fad2a1942011.gif`、`Material/2ca57d0da1e611c5284873ecbb0fc8514a9949c6.gif`。你可以用 `view_image` 看。特征：黑色小椭圆眼带白色高光点；眼睛上方两道向上弯的细弧（Usagi 标志性的"眉线"，在额头两侧）；小小的 "ω" 形嘴；两颊粉色椭圆腮红，上面有 3 道斜短线；线条深棕近黑 `#2B1A12`，粗细均匀。
- 已定方案：`.agent-router/target.md` D3。桌宠程序会用到的表情：`blink`（眨眼）、`happy`、`surprised`、`angry`、`sad`、`aa`（张嘴大喊）。

## 要求

### 1. 表情图集（`pipeline/face/draw_atlas.py`）
- 用 Python 画（Pillow 装在仓库外临时虚拟环境，或用 Blender 自带 Python 手写光栅化，二选一写进 README），输出两张 RGBA PNG：
  - `assets/model/face/eyes_atlas.png`：眼睛 + 眉线 + 腮红，4×4 格，每格 512×512。格子内容：`neutral`（默认）、`blink`（两眼闭成下弯短弧）、`blinkLeft`、`blinkRight`、`happy`（两眼 "^ ^" 上弯弧）、`angry`（眉线压低成倒八字、眼睛变小）、`sad`（眉线八字下垂、眼角泪光）、`relaxed`（半闭眼）、`surprised`（眼睛变大成圆、眉线抬高）。
  - `assets/model/face/mouth_atlas.png`：嘴，4×4 格，每格 512×512：`neutral`（ω 形小嘴）、`aa`（张大的嘴，深红口腔 + 粉舌）、`ih`、`ou`、`ee`、`oh`、`happy`（大张的开心嘴）、`angry`（大喊嘴，比 aa 更大）、`sad`（下弯小嘴）、`surprised`（小圆 O 嘴）。
- 线条与颜色照参考图；背景透明；每格内容居中、比例一致，格子边缘留 8% 透明边距防止取样串格。
- 输出一张 `assets/model/face/atlas_preview.png` 把两张图集的所有格子标上名字排开，方便主导审看。

### 2. 贴片网格（`face_usagi.py`）
- 从身体网格上取眼睛区域和嘴区域的面（按上面的五官位置外扩 15%），复制成两个独立网格 `FaceEyes`、`FaceMouth`，沿法线外移 0.0015，蒙皮权重全部给 `Head`。
- 沿 `face_normal` 平面投影生成 UV，使默认格（`neutral`）的图案正好落在原来雕刻五官的位置、大小与之吻合。
- 材质：MToon，`alphaMode: MASK`（cutoff 0.5）或 `BLEND`（二选一，写理由），不开描边，不受光照影响或阴影很弱（让五官始终是纯色线条），`renderQueueOffset` 保证画在身体上面。
- UV 默认缩放为 1/4（只显示一格），偏移指向 `neutral` 格。

### 3. 表情（VRM 1.0 expressions）
- 每个表情只用 `textureTransformBinds` 改对应贴片材质的 offset（scale 保持 1/4），`isBinary: true`。
- `happy`、`angry`、`sad`、`relaxed`、`surprised`：同时改眼睛和嘴两张贴片；`overrideBlink: block`、`overrideLookAt: none`、`overrideMouth: block`。
- `blink*`：只改眼睛贴片；`aa/ih/ou/ee/oh`：只改嘴贴片。
- 写清楚多个表情同时激活时的行为（UV offset 是相加的，靠 override + isBinary 避免串格），并在测试里覆盖"happy 激活时 blink 被阻止"。

### 4. 产物（`sh pipeline/build_usagi.sh face`，依赖 `rig` 阶段产物存在）
- `assets/model/usagi.vrm`（最终角色）、`assets/model/face/*.png`、`assets/model/usagi_face.report.json`（贴片顶点数、UV 范围、每个表情的绑定）。
- 表情预览 `assets/model/preview_face/`：每个表情一张正面近景（脸部特写，用 Workbench 或 Eevee 渲染，能看到贴图），拼一张 `expression_sheet.png`（格子下面标表情名）。

### 5. 测试（加进 `pipeline/run_tests.sh`）
- 图集：两张图尺寸 2048×2048、格子数量与名字表一致、每格非透明像素占比在合理范围（> 0.5%）、格子边距内全透明。
- 合成模型：在 010 测试用的合成角色上跑 face 阶段，断言两个贴片网格存在、权重全给 Head、UV 在 [0,1]、导出的 VRM 重新导入后表情列表完整、每个表情的 textureTransformBinds 指向正确材质、happy 的 overrideBlink 为 block。
