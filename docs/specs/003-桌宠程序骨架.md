## 目标

在 `app/` 下做一个跨平台（macOS / Windows）桌宠程序骨架：透明、无边框、置顶的小窗口里显示一个 VRM 角色，会呼吸、眨眼、眼睛跟着鼠标；能拖动、透明处点击穿透；托盘菜单能显示/隐藏、调大小、退出。现在用占位模型 `assets/placeholder/Seed-san.vrm`，以后换成 Usagi。

## 范围 / 不做什么

- 做：窗口、模型加载与渲染、待机动作、拖动、点击穿透、托盘菜单、本地配置、无头冒烟测试、单元测试。
- 不做：AI 聊天（下一份说明做）、音效、安装包打包、设置界面、开机自启。
- 不改 `app/` 以外的文件，`.gitignore` 只允许追加 `app/node_modules/`、`app/dist/`、`app/out/`、`app/smoke-out/` 这类构建产物行。

## 要求

### 技术栈

- Electron 当前稳定版、TypeScript（strict）、Vite 打包渲染进程、three、@pixiv/three-vrm、vitest。用 npm，提交 `package-lock.json`。
- 进程划分：`app/src/main/`（主进程）、`app/src/preload/`（contextBridge 暴露最小接口）、`app/src/renderer/`（three 场景）；`contextIsolation: true`、`nodeIntegration: false`。
- npm 脚本：`dev`（开发运行）、`build`、`typecheck`、`test`（vitest run）、`smoke`（见下）。`npm ci` 后这些命令不需要再装别的东西。

### 窗口

- 透明背景、无边框、无阴影、置顶（`alwaysOnTop` 用 `'floating'` 级别；mac 上 `setVisibleOnAllWorkspaces(true)`）、不显示在任务栏（Windows `skipTaskbar`）、mac 隐藏程序坞图标（`app.dock.hide()`）。
- 默认大小 320×420，初始位置在主屏幕右下角工作区内，离边缘 40 像素；位置和大小档位存到配置文件，下次启动恢复（位置超出当前屏幕时回到默认位置）。
- 大小三档：小 240×315、中 320×420、大 440×578（宽高比固定）。

### 模型与渲染

- 透明画布（`alpha: true`，清屏颜色透明），正交或小视角透视相机，模型自动居中、整身入画、脚在画面下方 5% 处。
- 用 `VRMLoaderPlugin` 加载；调用 `VRMUtils.removeUnnecessaryVertices`、`VRMUtils.combineSkeletons`（按 three-vrm 当前版本的推荐用法）；每帧 `vrm.update(delta)`（弹簧骨骼才会动）。
- 灯光：一盏方向光 + 环境光，保证 MToon 材质看起来正常。
- 加载失败时：画面显示一行错误文字（"模型加载失败：<原因>"），并写日志，不崩溃。

### 待机动作（`app/src/renderer/behaviors/`，每个行为一个文件，纯函数部分要能单测）

- 呼吸：胸部/脊柱骨骼小幅周期旋转，周期约 3.5 秒。
- 眨眼：每 2.5～6 秒随机眨一次，用 `blink` 表情，0.15 秒闭合再张开；模型没有 `blink` 表情时跳过，不报错。
- 看鼠标：主进程每 50ms 用 `screen.getCursorScreenPoint()` 取全局鼠标位置，通过 IPC 发给渲染进程；渲染进程换算成相对窗口的方向，设置 `vrm.lookAt` 的目标，头部骨骼也跟着小角度转（不超过 20°），平滑过渡。
- 点击：在模型上单击（按下与松开位置差 < 4 像素且时间 < 300ms）时播放 `happy` 表情 1.2 秒并小跳一下（根节点上下位移）；没有 `happy` 表情时只跳。

### 拖动与点击穿透

- 鼠标在模型不透明像素上时窗口接收鼠标；在透明像素上时 `setIgnoreMouseEvents(true, { forward: true })` 穿透到下面的窗口。判断方法：渲染进程按鼠标位置读取画布该点像素 alpha（WebGL `readPixels`，需 `preserveDrawingBuffer` 或在渲染后立即读取），alpha > 0.1 视为命中；判断结果变化时通过 IPC 通知主进程切换。命中判断的坐标换算写成纯函数并单测（含高 DPI 缩放比）。
- 在模型上按住左键拖动移动窗口（主进程按鼠标位移 `setPosition`），拖动结束保存位置。拖动不触发"点击"。

### 托盘菜单

- 托盘图标（先用程序生成的简单图标或 `app/resources/` 下一张 PNG，留 `TODO(lead): 换成 Usagi 图标`）。
- 菜单项（中文）：显示/隐藏桌宠、始终置顶（勾选）、大小 ▸ 小/中/大（单选）、重新载入模型、退出。

### 配置

- 配置文件 `config.json` 放在 `app.getPath('userData')`；读写封装成一个模块，带默认值合并和损坏文件容错（JSON 解析失败时备份为 `config.broken-<时间>.json` 并用默认值），这部分单测。
- 字段：`modelPath`（可空）、`size`（`small|medium|large`）、`position`（`{x,y}` 可空）、`alwaysOnTop`（默认 true）。

### 冒烟测试 `npm run smoke`

- 先构建，再用 Electron 以 `--smoke` 参数启动：窗口不显示（`show: false`）也要能离屏渲染（`webPreferences.offscreen: true` 或隐藏窗口 + `capturePage`，选可行的一种并在汇报里说明）。
- 加载占位模型，等模型加载完成后渲染约 60 帧，然后截图保存为 PNG：环境变量 `AR_GATE_ARTIFACT_DIR` 存在时写到该目录 `smoke.png`，否则写到 `app/smoke-out/smoke.png`。
- 检查：截图里 alpha > 0 的像素占比在 2%～95% 之间（说明有角色且背景透明）；在标准输出打印一行 JSON：`{"ok":true,"model":"<路径>","opaqueRatio":0.xx,"vrmVersion":"1","expressions":[...]}`，`ok` 为 false 时退出码 1。60 秒内没完成就以退出码 1 结束并打印原因。
- 冒烟模式下不创建托盘、不写配置文件、不轮询鼠标。

### 单元测试（vitest）

至少覆盖：配置读写与容错、命中判断坐标换算（含 DPR 1 / 2）、眨眼计时器（给定随机种子或注入随机函数，断言间隔在 2.5～6 秒）、点击与拖动的判定、大小档位计算、窗口初始位置计算（含越界回退）。
