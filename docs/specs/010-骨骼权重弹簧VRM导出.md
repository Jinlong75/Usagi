## 目标

把 009 产出的底模 `assets/model/usagi_base.glb` 做成可以动的 VRM 1.0 角色 `assets/model/usagi_body.vrm`：VRM 标准人形骨骼（适配 Q 版短手短脚）、两只耳朵各一串骨链、尾巴骨、可用的权重、耳朵弹簧骨骼与头/身碰撞体、MToon 平涂 + 深棕描边材质、VRM 元信息。用命令行脚本 `sh pipeline/build_usagi.sh rig` 一键生成，并出多姿态预览图检验权重。

## 范围 / 不做什么

- 不做：五官贴片与表情（011）、替换桌宠程序里的模型（之后的合流任务）、修改 `Material/`、修改 009 的底模算法（发现底模问题写进汇报 `TODO(lead)`）。

## 要求

### 1. 骨骼（Armature 名 `Armature`，骨骼名用英文）
按关键点生成，所有骨骼长度 > 0.01，子骨骼头接父骨骼尾或位于其附近：
- 躯干：`Hips`（骨盆中心，朝上）→ `Spine` → `Chest` → `Neck`（`neck` 关键点）→ `Head`（到 `head_top`）。
- 手臂（左右各一，角色左手 +X）：`UpperArm`（`arm_root` 到根-尖 40%）→ `LowerArm`（到 80%）→ `Hand`（到 `arm_tip`）；`Shoulder` 可选。
- 腿：`UpperLeg`（`leg_root`）→ `LowerLeg` → `Foot`（`foot`），短腿按比例分段；`Toes` 可选。
- 耳朵：`EarL_1..4`、`EarR_1..4`（沿 `ear_axis_l/r` 的 5 个点分 4 节），父骨骼 `Head`。
- 尾巴：`Tail`（从尾巴根到尾尖，父骨骼 `Hips`）。
- 骨骼滚转角统一（Z 轴朝前或按 VRM 插件推荐），在 README 写明。

### 2. VRM 人形映射（VRM 1.0）
必填骨骼全部映射：`hips, spine, head, leftUpperArm, leftLowerArm, leftHand, rightUpperArm, rightLowerArm, rightHand, leftUpperLeg, leftLowerLeg, leftFoot, rightUpperLeg, rightLowerLeg, rightFoot`；另映射 `chest`、`neck`。耳朵、尾巴不进人形映射。插件的人形校验不能有错误（警告列进报告）。

### 3. 权重
- 先尝试 Blender 自动权重（骨骼热量）。这个网格有 258 条非流形边，热量法可能失败或出现"Bone Heat Weighting failed"——**失败或质量不合格时改用几何法**：按到骨骼线段的距离加高度带平滑过渡计算权重，自己实现。
- 硬约束（测试要检查）：
  - 耳朵区域（头顶以上）的顶点只受 `EarX_n` 与 `Head` 影响，沿耳朵从根到尖逐节过渡，耳尖 1 节权重 ≥ 0.8。
  - `Tail` 只影响尾巴区域。
  - 手臂顶点不被腿骨影响，反之亦然；左边不被右边骨骼影响。
  - 每个顶点最多 4 个影响骨骼，权重和为 1（误差 1e-4），没有零权重顶点。
  - 脸部区域（`face_center` 周围 `face_radius*0.6` 内）只受 `Head` 影响（贴片和表情要贴在这里）。

### 4. 弹簧骨骼与碰撞体（VRM 1.0 SpringBone）
- 碰撞体：`Head` 上一个球（中心 `head_center`，半径为头部近似半径的 0.95）、`Chest` 上一个球（躯干），各自成碰撞组。
- 两只耳朵各一条弹簧：关节 `EarX_1..4`，初始参数：`stiffness 1.6`、`gravityPower 0.15`、`gravityDir (0,-1,0)`、`dragForce 0.45`、`hitRadius 0.012`；碰撞组为头 + 身体。
- 尾巴一条短弹簧（`Tail`，`stiffness 2.5`、`dragForce 0.6`），碰撞组为身体。
- 参数做成脚本顶部常量，方便后调。

### 5. 材质（MToon 1.0）
- `Body`：底色 `#FFF1C1`，阴影色 `#F0D9A0`；`EarInner`：`#F7B8C4` / `#E9A0B0`；`Tail`：`#FFFFFF` / `#E8E8EE`。
- 描边：世界坐标宽度 0.006（1.0 高度模型），颜色 `#4A2A1A`，全部材质开描边。
- 阴影偏硬（shadingShift / toony 取让明暗分界清晰的值），整体是 Chiikawa 平涂感。

### 6. VRM 元信息
`name: Usagi`、`version: 0.1`、`authors: ["Usagi Desktop Pet (personal)"]`、`licenseUrl: https://vrm.dev/licenses/1.0/`、`avatarPermission: onlyAuthor`、`commercialUsage: personalNonProfit`、`allowRedistribution: false`、`allowExcessivelyViolentUsage: false`、`allowExcessivelySexualUsage: false`、`allowPoliticalOrReligiousUsage: false`、`allowAntisocialOrHateUsage: false`、`creditNotation: required`、`otherLicenseUrl` 留空；`copyrightInformation: 角色版权归《Chiikawa》原作者，仅个人使用。`。

### 7. 产物（`sh pipeline/build_usagi.sh rig`）
- `assets/model/usagi_body.vrm`（VRM 1.0）、`assets/model/usagi_rig.blend`（可选，方便人工检查；超过 20MB 就不提交）、`assets/model/usagi_rig.report.json`（骨骼列表与长度、人形映射、权重统计：每骨影响顶点数、最大影响数、未归一化顶点数、耳朵/脸部约束检查结果、热量法是否成功、弹簧与碰撞体参数、插件校验警告）。
- 姿态预览 `assets/model/preview_rig/`：中性 T 姿、双臂上举、双臂下垂 70°、头左转 30°、两耳向后弯（每节 25°）、单腿抬起，每个姿态出正面和斜 45° 两张，再拼一张 `pose_sheet.png`。用于检查权重：手臂抬起时身体不被拉扯、耳朵弯时头不变形、头转时身体不扭。

### 8. 测试（加进 `pipeline/run_tests.sh`）
合成模型（球身 + 两根耳柱 + 两根短臂柱 + 两根短腿柱 + 小尾巴球，附合成关键点）跑 rig：断言人形必填骨骼齐全、骨骼长度 > 0.01、权重硬约束全部满足、导出的 .vrm 能用 VRM 插件重新导入且人形映射一致、弹簧关节与碰撞体数量正确。
