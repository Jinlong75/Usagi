## 目标

用户 2026-11-16："可以把桌宠吸附到窗口的顶端坐下"；确认"两种都有"（拖过去松手坐上去 + 闲逛时偶尔自己跳上去），本轮就做（D10、D13）。同时实现 020 留下的 `isForegroundFullscreen()`（`TODO(D10)`）。

## 读别的程序的窗口（`app/src/main/perch/windows.ts`）

- 用 **koffi**（npm `koffi`，自带各平台预编译二进制，不需要本机编译；版本写死）在主进程调系统接口；`electron-builder.yml` 让 koffi 的 `.node` 文件 `asarUnpack`。**核实**：`npm --prefix app run dist` 不在本任务验收里跑，但汇报要写清 win32-x64 与 darwin-arm64 的预编译文件都会打进包（列出路径）。
- 统一返回 `WindowInfo[]`（从上到下的 z 顺序）：`{ id, bounds: {x,y,width,height}（Electron 屏幕坐标，DIP）, minimized, ownerPid?, title? }`。
  - **Windows**：`EnumWindows`（顺序即 z 序，从上到下）+ `IsWindowVisible` + `IsIconic` + `DwmGetWindowAttribute(DWMWA_EXTENDED_FRAME_BOUNDS)`（去掉阴影的真实边框）+ `DWMWA_CLOAKED` 过滤隐藏的 UWP 窗口 + 过滤 `WS_EX_TOOLWINDOW`、无标题、宽或高 < 120 的窗口、桌面（Progman/WorkerW）和任务栏（Shell_TrayWnd）。物理像素用 `screen.screenToDipRect(null, rect)` 转成 DIP。
  - **macOS**：`CGWindowListCopyWindowInfo(kCGWindowListOptionOnScreenOnly | kCGWindowListExcludeDesktopElements, kCGNullWindowID)`，经 CoreFoundation 取 `kCGWindowBounds`（`CGRectMakeWithDictionaryRepresentation`）、`kCGWindowLayer`（只要 0 层）、`kCGWindowOwnerPID`；坐标已是左上原点的点，与 Electron 一致。不读窗口标题（不需要屏幕录制权限）。
  - 两个平台都排除本程序自己的窗口（按 pid）。
  - koffi 加载失败或调用出错：整个吸附功能与全屏检测**静默关闭**（返回空列表 / `false`），主进程日志写一行原因，不弹错。
- `isForegroundFullscreen()`：最上层的普通窗口覆盖它所在显示器的**完整 bounds**（不是 workArea，容差 2px）即为 true。Windows 用 `GetForegroundWindow`，mac 用列表第一个 0 层窗口。接到 `routine.ts`（替换 020 的恒 false），每 2 秒刷新一次缓存，不在每次检查时调系统。

## 吸附规则（纯逻辑放 `app/src/main/perch/logic.ts`，注入窗口列表与时间，单测覆盖）

- **"座位点"**：桌宠模型臀部底沿的屏幕坐标（从桌宠窗口 bounds 与渲染层上报的模型脚底/臀部位置换算；渲染层已有 `headTop` 上报，照此加 `seat` 上报）。
- **可坐的窗口**：可见、未最小化、上沿 `y >= workArea.y + 40`（最大化或贴顶窗口不坐）、宽 ≥ 240，并且座位点所在的那一段上沿**没有被更上层的窗口盖住**。
- **拖过去松手**：松手时座位点离某个可坐窗口上沿竖直距离 ≤ 30px、水平落在 `[left+30, right-30]` 内 → 吸附：桌宠窗口移到让座位点正好在上沿（动画 180ms），进入"坐着"。多个候选取 z 序最上面的。
- **自己跳上去**：随机池加 `perchHop`，低权重（与 024 新动作同权重），且距上次自己跳上去 ≥ 10 分钟、设置 `perch.auto` 开着、不全屏；目标是座位点水平 ±400px 内、上沿高于当前座位点的最近可坐窗口；跳的轨迹是 0.7 秒抛物线（最高点比上沿再高 60px），起跳前蹲一下、落地压扁一下（复用 `jumps` 的压扁参数）。没有目标就不选这个动作。
- **坐着时**：每 100ms 轮询窗口列表——窗口移动 → 跟随（保持相对水平位置）；窗口最小化 / 关闭 / 被别的窗口盖住座位点 / 变成最大化 / 上沿移出可坐范围 → **跳下**：0.5 秒抛物线落到当前显示器 workArea 底部（与平时的地面高度一致），落地压扁。用户拖动 → 解除吸附，按普通拖动处理。坐着时不随机走路，随机动作只播不移动的（idle、lookAround、stretch、shake、吹泡泡、进食、打盹……；jump/spin/jumpRope 不播）。
- **坐姿 `sit`**（渲染层 `sampleMotion`）：臀部下沉、两条小腿向前抬起（upperLeg 绕 X 约 1.2 rad，方向先核实），双脚悬在窗口外沿，脚每 3 秒轻轻晃一次（±0.15 rad）；上半身不变，表情 neutral。坐着时持续保持这个姿态，其他动作叠加在它上面。
- 设置：`Config.perch = { enabled: true, auto: true }`；设置页加"可以坐到窗口上""自己跳到窗口上"两个勾选；右键菜单在坐着时多一项"下来"（触发跳下）。
