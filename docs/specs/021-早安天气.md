## 目标

用户 2026-11-16 要求早上问好时"说天气怎么样"，定位方式选"按照 ip 自动定位"（D9）。020 已在 `routine.ts` 留了 `weatherLine(): Promise<string | null>` 接口（注入恒返回 null），本任务实现它并接上。

## 要求

新建 `app/src/main/weather.ts`，网络请求一律用 Electron `net.fetch`（走系统代理），每个请求 5 秒超时。函数接受注入的 `fetch` 与 `now()`，测试不联网。

1. **定位**（按顺序试，前一个失败才试下一个）：
   - `https://api.ip.sb/geoip` → 取 `latitude`、`longitude`、`city`
   - `https://get.geojs.io/v1/ip/geo.json` → 取 `latitude`、`longitude`（字符串，转数字）、`city`
   - 经纬度不是有限数字算失败。定位结果缓存 24 小时，存 `userData/weather-cache.json`（原子写，读坏了丢弃重来）。
2. **天气**：`https://api.open-meteo.com/v1/forecast?latitude=<lat>&longitude=<lon>&current=temperature_2m,weather_code&daily=weather_code,temperature_2m_max,temperature_2m_min,precipitation_probability_max&timezone=auto&forecast_days=1`。结果缓存 1 小时（同一缓存文件）。
3. **一句话**：`今天<天气>，<最低>～<最高>°C` + （降水概率 ≥ 50% 时）`，记得带伞`。温度四舍五入取整。天气用 `daily.weather_code[0]` 按 WMO 代码映射：0 晴；1、2 多云；3 阴；45、48 雾；51–57 毛毛雨；61–67 雨（65、67 写"大雨"）；71–77 雪；80–82 阵雨；85、86 阵雪；95–99 雷雨；其他写"天气"（即"今天天气，…"不好看，改为省略天气词：`今天<最低>～<最高>°C`）。
4. 任一步失败（网络、超时、HTTP 非 2xx、字段缺失）都返回 `null`，不抛错、不弹提示，只在主进程日志写一行原因。
5. 接到 `routine.ts`：问好时调用（020 已有 3 秒超时，超时用原句）。程序启动后 5 分钟内若处在早上时段，预取一次填缓存，避免问好时等网络。

## 设置

`Config.routine` 加 `weather: boolean`（默认 `true`）。设置页"作息"一节加勾选"早上说天气"，下方灰字：`会用你的网络 IP 查大致位置（ip.sb / geojs.io），再从 Open-Meteo 查天气；不需要账号。` 定位成功后在灰字下显示 `当前位置：<city>`（读缓存，没有就不显示）。关掉时 `weatherLine` 直接返回 null、不发任何请求。

## 测试（`app/tests/weather.test.ts`，注入假 fetch 与假时钟）

至少覆盖：第一个定位源失败退到第二个；两个都失败返回 null；定位缓存 24 小时内不再请求、过期重请求；天气缓存 1 小时；WMO 代码映射（每个分组至少一个）；降水 ≥ 50 加"记得带伞"、49 不加；温度取整；未知代码省略天气词；超时返回 null；HTTP 500 返回 null；`weather=false` 不发请求；缓存文件损坏时重来。
