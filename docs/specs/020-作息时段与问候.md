## 目标

用户 2026-11-16 原话："桌宠会读系统时钟，比如说早上会向用户问好，说天气怎么样，问用户早上吃了什么，中午会问用户吃饭没，会午睡，晚上会睡觉，提醒用户早睡"；确认"气泡说口癖""上面表的时间合适"。决定见 `.agent-router/target.md` D9。

本任务做**作息调度 + 问候气泡 + 问话接聊天 + 设置**。不做：天气（021 做，本任务留接口）、睡觉/打瞌睡的身体动作和闭眼（等五官图集重画后另派，本任务只发出状态事件）、全屏检测（D10 吸附任务用 koffi 做，本任务留接口）。

## 时段（默认值，设置里可改）

| 键 | 时段 | 行为 |
|---|---|---|
| `morning` | 06:00–10:00 | 问好 + 问早饭（问话） |
| `lunch` | 11:30–13:00 | 问吃饭没（问话） |
| `nap` | 13:00–14:00 | 说困了要午睡；发状态 `nap`，时段结束发 `awake` |
| `dinner` | 17:30–19:00 | 问晚饭（问话） |
| `bedtime` | 从 22:30 起 | 提醒早睡；之后每 30 分钟一次，最多 3 次（22:30、23:00、23:30） |
| `sleep` | 00:00–06:00 | 说晚安；发状态 `sleep`，到 06:00 发 `awake` |

- **逻辑日**以 05:00 为界（00:00–04:59 算前一天），保证 bedtime 与 sleep 跨午夜不重复、不漏。
- **触发**：每 30 秒检查一次。当前在某时段内、该时段该逻辑日还没触发、用户在电脑前（`powerMonitor.getSystemIdleTime() < 60` 秒）、且不被挡住（复用 selfTalk 的 `blocked()`：桌宠隐藏、正在拖、设置/聊天窗口开着、聊天气泡占用；另加 `isForegroundFullscreen()`，本任务实现为恒返回 `false` 并注释 `TODO(D10)`），就触发一次。错过整个时段（例如 10 点后才开电脑）**不补**。
- **离开回来**：系统空闲 ≥ 30 分钟后恢复活动，且不在 `nap`/`sleep` 时段、距上次"回来"招呼 ≥ 2 小时，说一句回来招呼。
- **去重持久化**：每个时段最后触发的逻辑日、bedtime 当天已提醒次数、上次回来招呼时间，存 `app.getPath('userData')/routine-state.json`（临时文件 + rename 原子写；读坏了改名 `.broken-<时间戳>.json` 重新开始，同 `config.ts` 写法）。重启程序同一时段不重复。
- **免打扰**（`quiet`）开着：不出作息气泡、不出声，但状态事件照发。`enabled=false`：整个作息停掉，不发任何事件。
- `nap` / `sleep` 状态期间暂停自言自语（`SelfTalk` 的 `blocked`），`awake` 后恢复。
- 时钟和空闲时间都通过注入的接口取（`now(): Date`、`idleSeconds(): number`），测试用假时钟，不真等。

## 台词（主导定稿，原样使用；同时段多句时用 `chooseLine` 避免连续重复）

格式统一为"口癖（中文意思）"。

- morning：`呀哈！（早上好～早饭吃了什么？）`、`呀哈呀哈！（起床啦～早饭吃了没？）`、`哈？（天亮了！早饭吃了什么呀？）`
- lunch：`乌拉！（中午啦，吃饭没？）`、`呀哈～（午饭吃什么呀？）`、`噗噜噜……（肚子饿了，你吃饭没？）`
- nap：`呼……噗噜……（困了，午睡一下）`、`哈啊～（好困……睡一会儿）`
- dinner：`呀哈！（晚饭时间到～吃什么？）`、`乌拉～（晚饭吃了没？）`
- bedtime 第 1/2/3 次分别：`哈？（这么晚了，早点睡哦）`、`乌拉！（还不睡？快去睡觉！）`、`噗噜噜……（我先睡了，你也快睡）`
- sleep：`呼……（晚安）`
- 回来：`呀哈！（回来啦～）`、`哈？（去哪了？回来啦！）`

叫声：每次作息气泡播一次现有的随机叫声（和 selfTalk 同一个 `sound()`）；`quiet` 时不播。

## 问话气泡接聊天

- morning / lunch / dinner 是**问话**：气泡显示 10 秒，期间**可以点**（`BubbleWindow` 显示问话时 `setIgnoreMouseEvents(false)`，隐藏或换成普通气泡时恢复 `true`；普通气泡和 selfTalk 气泡仍然点不到）。点击 → 打开聊天窗口（`ui.chat.open()`），并把这句气泡的**括号里的中文**作为一条 `assistant` 消息追加进当前会话（新增 `ChatService.appendAssistant(text)`，走现有的落盘写法），这样用户接着回答时 DeepSeek 有上下文。没填 Key 时聊天窗口照现有逻辑提示去设置。
- 问好时如果天气接口给了结果（`weatherLine(): Promise<string | null>`，本任务注入恒返回 `null` 的实现，021 替换），把它插在中文括号里问句前，例如 `呀哈！（早上好～今天晴，12～20°C。早饭吃了什么？）`。接口返回 null 或 3 秒超时就用原句。

## 状态事件

新增主进程 → 桌宠窗口事件 `routine:state`，值 `'nap' | 'sleep' | 'awake'`（preload 暴露 `onRoutine(callback)`，类型写进 `shared/types.ts` 的 `PetBridge`）。本任务桌宠渲染层**不接**（不改 `app/src/renderer/**`），后续动作任务接入。

## 设置

`Config` 新增：

```ts
routine: {
  enabled: boolean;            // 默认 true
  quiet: boolean;              // 默认 false（免打扰）
  morning: [string, string];   // 'HH:MM'，默认 ['06:00','10:00']
  lunch: [string, string];     // ['11:30','13:00']
  nap: [string, string];       // ['13:00','14:00']
  dinner: [string, string];    // ['17:30','19:00']
  bedtime: string;             // '22:30'
  sleep: [string, string];     // ['00:00','06:00']
}
```

`normalizeConfig`：非法时间（不是 `HH:MM`、小时 > 23、分钟 > 59）回落默认；开始等于结束视为该时段关闭。设置页加"作息"一节：两个勾选（"按作息问候""免打扰"）和每个时段的时间输入，文案用上表"时段"列的中文名（早上、中午、午睡、晚饭、催睡、睡觉）。右键/托盘菜单加勾选项"免打扰"。
