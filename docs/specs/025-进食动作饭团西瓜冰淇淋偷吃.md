## 目标

D11/D13：用户点名"乌萨奇可以吃东西"。在 024 的道具框架（`app/src/renderer/props/`、`Pose.props`、`PropRig`、`pet:activity` IPC、"玩耍"子菜单）上做 4 个进食动作。开工先读 024 合入后的代码与 `docs/specs/024-道具框架与跳绳吹泡泡打盹.md`，沿用同一套约定（坐标为模型高度分数、平涂 + 反向外壳描边 `#2b1a14`、首尾 neutral、取景包含道具、dispose 回收）。

五官（023 起）：`aa` = 大开 ω（咬），`sad` = 鼓腮咀嚼 ω，`happy` = 小开 ω（满足），`surprised` = 圆眼小开 ω（"哈？"）。进食时**眼睛保持圆眼**（原作吃东西时眼不变形，018 F11～F13）。

手臂短：食物**飘在嘴前偏下**，两只小手在食物两侧下方小幅上抬（上臂抬角 ≤ 0.3 rad），不追求真正握住。

## 四个动作（主导定的时长与要点）

1. **大口吃饭团 `eatRiceball`**，6 秒：圆角三角饭团（白 `#fbfbf5`，宽 0.16H，可用压扁的三棱柱+倒角或缩放球体拼）+ 底部黑色海苔薄片（`#2e3b2c`）。节奏：食物从下方升到嘴前（0.6 秒）→ 咬 3 次，每次：头前探 0.08 rad + `aa` 0.25 秒 → `sad` 咀嚼 0.9 秒（身体随咀嚼 Y 向轻压 3%，两次压缩）；每咬一次饭团缩小一段（1 → 0.65 → 0.3 → 消失，消失时冒 3～5 个白色小米粒向下落）→ 最后 `happy` 1 秒、身体小跳一次。结束播 `click_happy`（呀哈）。
2. **啃西瓜 `eatWatermelon`**，5 秒：半圆楔形西瓜（红瓤 `#ef5a5a`、白边 `#f3f1e4` 窄条、绿皮 `#3f9b4b`、4～6 颗黑籽 `#2b1a14` 小椭球），宽 0.2H，弧边朝上。头左右各啃一下再中间一下（3 次），每次 `aa`→`sad`，西瓜每次在被啃的位置缺一口（用缩放/裁切近似：瓤高度递减即可），头和耳朵随啃左右轻倾 0.1 rad。结束 `happy`。
3. **舔冰淇淋 `iceCream`**，5.5 秒：圆锥（`#e3b26b` 饼干色，高 0.12H）+ 粉色球（`#f7a8c4`，半径 0.05H）。身体前倾去够（不是手举到嘴），`ih` 口型舔 4 次（每次 0.4 秒）；第 3 次舔后一滴粉色小球从球边滴落（0.8 秒落出取景下沿前消失）→ 头向后缩、`surprised` 0.6 秒 → 再舔一下 → `happy`。
4. **偷吃被发现 `sneakSnack`**，4.5 秒（随机池专用，不进菜单）：一块小饼干（扁圆柱 `#d9a05b`，半径 0.04H）藏在身体侧前方；头左右各偷看一次（转头 0.25 rad，0.5 秒），然后快速 `aa`/`sad` 咀嚼 2 次。**被点击时**（在这个动作进行中点到桌宠）：立刻进入"被抓住"反应——全身僵住 0.4 秒（动作暂停、`surprised`、耳朵竖起：两耳弹簧短暂加刚度或给根骨一个后仰脉冲）、饼干缩到身后隐藏，然后播 `click_surprise`（"哈？"）并接正常点击反应流程。

## 触发

- 右键/托盘菜单新增子菜单"喂食"：`饭团`、`西瓜`、`冰淇淋`（放在"玩耍"上面）。点了立即播放（同 024 的打断规则：打断 idle/act/move，不打断拖动）。
- 随机池：`sneakSnack` 低权重（与 024 的新动作同权重）；其余三个只由菜单触发。
- 作息：早上 / 中午 / 傍晚时段问话气泡出现后的 2 分钟内，如果用户点了"喂食"任一项，吃完后多冒一句气泡 `呀哈！（好吃！）`（主进程 `ui.bubble.showBubble`，3.2 秒）；不在这些时段就不冒。

## 冒烟与测试

- `SmokeBehavior`/`BEHAVIORS` 加 `eatRiceball`、`eatWatermelon`、`iceCream`、`sneakSnack`，截图取"食物在嘴前、正在咬（`aa`）"的时刻；报告断言道具可见（同 024 的方法）。
- 测试：每个动作首尾 neutral 且道具隐藏；饭团三段缩小后消失；西瓜每次啃后变小；冰淇淋滴落发生在第 3 次舔之后；偷吃中点击 → 僵住 0.4 秒并隐藏饼干、发 `click_surprise`；"喂食"菜单三项发对 IPC；作息时段内喂食后冒"好吃"气泡、时段外不冒。
