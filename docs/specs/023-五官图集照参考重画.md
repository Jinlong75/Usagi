## 目标

用户 2026-11-16："现在的表情只能说合格但不符合乌萨奇这个角色的特点"；"乌萨奇在发出不同声音的时候会有不同的表情。动态图也有不同的表情下五官的变化"。018 已整理出原作五官特写：`docs/research/usagi-表情动作/face/overview.png`（F01～F22，说明在同目录 `REPORT.md` 与 `README.md`）。现有图集 `assets/model/face/atlas_preview.png` 的问题：张口全是椭圆、有怒眉八字眉、neutral 嘴形状不对、眼睛下有多余的小笑弧。

**本任务按主导定稿的形态照参考描线重画图集**，并把贴片位置按 022 换的新模型 `Material/tripo/usagi3d2.glb` 重新量。图集布局、表情名、VRM 表情绑定的结构都不变（app 不用改）。

## 主导定稿（照做，不另作审美选择）

**通则**：线条深棕 `#2b1a14`（沿用现色），粗细比现在细约 25%，以 F01 的线宽与头宽比例为准；所有格子的**眉毛完全相同**：两道高弧，位置、长度照 F01/F02（眉梢在眼外侧上方、弧顶远高于眼睛）。腮红：粉色椭圆 + 3～4 条短斜线（照 F01，线比现在细、颜色比粉底深一号）。

**眼睛（FaceEyes 各格）**：

| 格 | 画法 | 参照 |
|---|---|---|
| neutral | 黑色实心圆眼，比现在大约 1.3 倍；左上方一个白色椭圆高光（约眼径 40%）；**去掉眼睛下方的小笑弧** | F01、F02、F05 |
| blink | 两条短横线（眼径宽、线宽同描线），位置在圆眼中心 | F09 |
| blinkLeft / blinkRight | 一侧短横线、另一侧 neutral 圆眼 | F09/F10 |
| happy | 与 neutral 相同 | F06、F19（叫"呀哈"时仍是圆眼） |
| surprised | 与 neutral 相同 | F19（"哈？"仍是圆眼） |
| angry | 与 neutral 相同（原作没有怒眉，主导决定不画） | F06 长叫仍圆眼弧眉 |
| sad | 与 neutral 相同 | — |
| relaxed | 两道向上拱的闭眼弧（∩ 形，弧宽约眼径 1.3 倍） | F08 |

**嘴（FaceMouth 各格）**——所有张口都保留 **ω 上沿**（两个相连小弧，中间尖点朝上），开口从 ω 下方向下长出，**不画完整椭圆**：

| 格 | 画法 | 参照 |
|---|---|---|
| neutral | 闭口 ω：两个小弧 + 中间朝上尖点，左侧带一个向下的小尾钩 | F01、F02 |
| relaxed | 同 neutral | — |
| ih / ee / ou / happy / surprised | 小开 ω：ω 上沿下方一个浅 U 形开口（高约 ω 宽的 0.6），深棕口腔，底部粉色小舌 `#f08aa0` 系；开口下方一条短下唇弧 | F03、F19、F21 |
| aa / oh / angry | 大开竖长 ω：ω 上沿下方竖长 U 形开口（高约 ω 宽的 1.3～1.5），口腔深棕红，底部粉舌占开口下 1/3；下方短下唇弧 | F05、F06 |
| sad | 鼓腮咀嚼：ω 中部向内挤成紧缩的小 ω（宽约 neutral 的 70%），两侧各一道短弧表示鼓起的腮（以后吃东西用） | F11、F12、F13 |

## 要求

1. **贴片位置按新模型重量**：`pipeline/face/layout.py` 的 `SCULPTURE`、`FRAMES`、`MOUTH_BOUNDS`、`CHEEK_CENTERS` 等是按旧模型 `usagi_3d.glb` 的雕刻五官量的。改为从 `usagi3d2.glb` 的雕刻五官实测（写一个可重复的量取函数或脚本，结果写进 layout 并在测试里校验与实测一致，容差 2 mm）。量出的眼、眉、嘴、腮位置与参考 F01 的比例对照，汇报写数字。
2. 重画 `pipeline/face/draw_atlas.py` 的各格（按上表），图集布局（`EYES`/`MOUTHS`/`EXPRESSIONS` 顺序、`CELL`、`MARGIN`）不变。
3. 整条 face 阶段重出：`sh pipeline/build_usagi.sh face`，然后 `cp assets/model/usagi.vrm assets/models/usagi.vrm`。prep、rig 不动（022 已出）。
4. 验收产物：`assets/model/face/atlas_preview.png`（新图集）；新增 `assets/model/preview_face/compare_reference.png`：左右并排——左边 F01/F05/F09/F19/F12 五张参考特写，右边同表情下我们模型的正脸渲染（neutral、aa、blink、happy、sad），同头宽对齐。
5. 冒烟：`happyFaceDifferenceRatio > 0` 保持成立（happy 嘴从闭 ω 变小开 ω）。若 smoke 里别的五官相关断言因新图形失败，写"需要越界"停下（`app/**` 不在范围）。
6. 不做：改 app、改表情名或数量、改耳朵/身体/骨骼；不改 `docs/specs/checks/**`；做不通就停下汇报。
