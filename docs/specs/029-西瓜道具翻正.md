## 目标

用户 2026-11-17："喂食的西瓜整个西瓜是倒过来的。"截图 `docs/research/用户反馈-1117/西瓜倒置.png`：现在西瓜片是"拱门"形——绿皮弧边在上、平的切面在下。

改成常见的西瓜片朝向（和 🍉 一样）：**绿皮弧边朝下，平的切面朝上对着嘴**，啃的缺口从平的切面那边往下吃。

## 原因（主导已核实）

`app/src/renderer/props/index.ts` 约 118 行的 `halfDisc`：`shape.absarc(0, 0, radius, Math.PI, 0, true)` 在 three.js 里顺时针从 π 走到 0，经过 π/2，画的是**上半圆**。

## 要求

- `halfDisc` 改为画下半圆（弧经过 3π/2），三层（绿皮 `rind`、白瓤 `rindWhite`、红瓤 `melon`）一起翻；整体位置不变：平的切面仍在原来平边的高度附近、对着嘴，西瓜整体不往上或往下跳。核对 `translate(0, -0.045, ...)` 翻转后是否还需要，以截图里西瓜在嘴前、不挡眼睛为准。
- 瓜子（5 个黑点，约 126 行）跟着移到红瓤里面（原来的 y 取反后再核对都在红瓤内）。
- `foodRemaining` 吃掉的效果（约 141～145 行，`melonFlesh[0]` 的 `position.y = -0.045 * (1 - remaining)`）：改成**从平的切面往弧边方向**一口口变少，吃完时只剩绿皮弧边；瓜子在被吃掉的部分里时隐藏。
- `app/src/renderer/motion/food.ts` 里西瓜的位置（约 46 行 `position: [0, 0.275, 0.36]`）只在翻转后位置明显不对时微调，汇报写原值与新值。
