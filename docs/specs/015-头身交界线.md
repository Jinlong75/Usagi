## 目标

用户在 Windows 上实测（2026-11-16）："模型应当是乌萨奇的头和身子之间有线……具体你可以参考 material 下的 chatgpt 四视图进行修改"。参考图 `Material/tripo/usagi_3d_ref.png` 左侧"正面"：头的黑色轮廓线沿两侧下来，到小手位置**向内收进一个凹口**，紧接着就是小手的弧线；也就是说从正面看，**头和身体在左右两侧各有一道清楚的黑线分界**（只在两侧，肚子正中没有横线）。我们的桌宠里（`app/smoke-out/smoke-idle.png`，或门禁冒烟截图）两侧轮廓是平滑鼓出的，看不到这道线。

底模其实有腰线凹槽（`assets/model/preview/preview_front.png` 能看到，D8 用户要求保留），但凹得太浅，MToon 描边（反向外壳，只在轮廓处可见）描不出来。

## 范围 / 不做什么

- 做：让桌宠正面、3/4 侧看时，两侧头身交界处出现一道与描边同色、同粗细观感的线，形状照参考图（从侧面轮廓向内、略向下弯，接到小手上方）。
- 推荐做法（可换等价做法，汇报写理由）：在 prep 阶段只在**身体两侧**（离正中 |x| 大于头宽 60% 左右的范围、高度在腰线凹槽 ±一小段）把腰线凹槽**加深**成明显的凹口，深度要足以让正面看时轮廓出现内凹、MToon 描边画出线；肚子正面不加深，保持现状。如果加深后描边仍不明显，再考虑在凹口里加一条与五官贴片同法的黑色细线贴片（绑到 Spine/Chest，MASK、queue 0）。
- 手臂：主导已把桌宠里手臂静止下垂角从 1.1 改为 0.35（`app/src/renderer/motion/index.ts` 的 `ARM_REST`，提交 5907386），小手现在停在凹口处，手上方的鼓包已消失。本任务**不改 app/**；如果凹口位置和小手对不上，写进汇报由主导调 `ARM_REST`。
- 不做：改颜色、五官、耳朵/尾巴分区、骨骼与弹簧参数；不改 `docs/specs/checks/**`；不改 `pipeline/face/draw_atlas.py` 的嘴型（主导定过）。
- 整条流水线重出：`sh pipeline/build_usagi.sh prep`、`rig`、`face`，然后 `cp assets/model/usagi.vrm assets/models/usagi.vrm`（app 测试要求两者逐字节一致）。
- 做不通就停下汇报，不改清单以外的文件。
