## 目标

用户 2026-11-16 原话："具体的表情参考你可以全量查看 material 下的视频和动态图，里面有很详细的表情参考，参照里面的表情来做，你可以截图截取表情作为参照，现在的表情只能说合格但不符合乌萨奇这个角色的特点"。同一天用户还说明："乌萨奇在做不同动作和表情的时候，五官的形态是不会发生变化的……只做位置的改变"。

本任务只做**整理参考**，给主导拍板用，不改程序和模型。

## 素材

- `Material/*.gif`（23 个）与 `Material/Usagi_Voice.mp4`。
- 视频抽帧可用 `/private/tmp/usagi-audio-venv/lib/python3.14/site-packages/imageio_ffmpeg/binaries/ffmpeg-macos-aarch64-v9.0`（005 留下的，可直接调用）；GIF 用 Pillow（可在仓库外临时 venv 安装，参考 `app/build/README.md` 的写法）。不要把工具装进仓库。

## 要求

1. 每个 GIF：抽取能代表动作变化的关键帧（按帧差挑，通常 4～12 帧），拼成一张带帧号与时间的拼图 `docs/research/usagi-表情动作/gif/<原文件名前 8 位>.png`（宽不超过 1600px）。
2. 视频：按镜头切换和画面变化抽帧（只保留有乌萨奇的画面），每段一张拼图放 `docs/research/usagi-表情动作/video/`，文件名带起止秒数。
3. `docs/research/usagi-表情动作/README.md`：
   - 一张总表：每个 GIF/视频片段 → 拼图路径、乌萨奇在做什么（动作）、五官当时的样子（眼、嘴、眉、腮红是否变形；是否只是随头移动）、身体与耳朵怎么动（幅度、节奏、时长约几秒）、伴随的典型叫声（若视频里能听到/看出）。
   - 归纳：乌萨奇区别于普通 Q 版兔子的动作与表情特点（例如蹦跳方式、耳朵怎么甩、手怎么动、身体是否挤压变形、停顿与节奏、脸部是否始终保持同一表情），每条注明出处拼图。
   - 和我们现有动作的对照：`idle/walk/happy/surprised/shout/stretch/drag/ear-shake/spin/turn/lookAround`（定义在 `app/src/renderer/motion/index.ts` 的 `sampleMotion`，冒烟截图在门禁或 `app/smoke-out/`），逐个说参考里对应的是哪段、我们差在哪里（幅度、节奏、姿势、缺了什么）；参考里有、我们没有的动作单列。
   - 五官：参考里五官**有没有**形态变化（张嘴、眯眼、哭、生气眉）。若有，列出出现的片段与帧号，写清楚是"偶尔特写才变"还是"动作时也变"；主导会据此和用户说的"不变"核对。
4. 只看画面得出的判断写"推断"，不确定的写"看不清"，不要编。
