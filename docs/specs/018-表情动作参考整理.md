## 目标

用户 2026-11-16 原话："具体的表情参考你可以全量查看 material 下的视频和动态图，里面有很详细的表情参考，参照里面的表情来做，你可以截图截取表情作为参照，现在的表情只能说合格但不符合乌萨奇这个角色的特点"。同一天用户先说过"五官的形态是不会发生变化的……只做位置的改变"，随后纠正："五官的动作和表情不是绝对保持原样的。你可以看 material 下的视频 usagi voice。乌萨奇在发出不同声音的时候会有不同的表情。动态图也有不同的表情下五官的变化。"——以纠正后的说法为准：**五官会随叫声和情绪变化**，本任务要把每种变化整理清楚。

本任务只做**整理参考**，给主导拍板用，不改程序和模型。

## 素材

- `Material/*.gif`（23 个）与 `Material/Usagi_Voice.mp4`。
- 视频抽帧可用 `/private/tmp/usagi-audio-venv/lib/python3.14/site-packages/imageio_ffmpeg/binaries/ffmpeg-macos-aarch64-v9.0`（005 留下的，可直接调用）；GIF 用 Pillow（可在仓库外临时 venv 安装，参考 `app/build/README.md` 的写法）。不要把工具装进仓库。

## 要求

1. 每个 GIF：抽取能代表动作变化的关键帧（按帧差挑，通常 4～12 帧），拼成一张带帧号与时间的拼图 `docs/research/usagi-表情动作/gif/<原文件名前 8 位>.png`（宽不超过 1600px）。
2. 视频：按镜头切换和画面变化抽帧（只保留有乌萨奇的画面），每段一张拼图放 `docs/research/usagi-表情动作/video/`，文件名带起止秒数。
3. `docs/research/usagi-表情动作/README.md`：
   - 一张总表：每个 GIF/视频片段 → 拼图路径、乌萨奇在做什么（动作）、五官当时的样子（眼、嘴、眉、腮红是否变形；是否只是随头移动）、身体与耳朵怎么动（幅度、节奏、时长约几秒）、伴随的典型叫声（若视频里能听到/看出）。
   - 归纳：乌萨奇区别于普通 Q 版兔子的动作与表情特点（例如蹦跳方式、耳朵怎么甩、手怎么动、身体是否挤压变形、停顿与节奏、脸部是否始终保持同一表情），每条注明出处拼图。
   - 和我们现有动作的对照：`idle/walk/happy/surprised/shout/stretch/drag/ear-shake/spin/turn/lookAround`（定义在 `app/src/renderer/motion/index.ts` 的 `sampleMotion`，冒烟截图在门禁或 `app/smoke-out/`），逐个说参考里对应的是哪段、我们差在哪里（幅度、节奏、姿势、缺了什么）；参考里有、我们没有的动作单列。
   - 五官（重点）：参考里五官的每一种形态（眼：圆点/眯/闭/瞪大/哭…；嘴：闭/小开/大张/特定形状；眉、腮红、汗滴等附加元素）分别在哪些片段与帧号出现，和哪个动作、哪种叫声一起出现；写清楚做普通动作（走、跳、挥手）时五官是否保持不变、只在叫/情绪时才变。
4. **叫声 ↔ 表情对照（重点）**：`assets/sounds/usagi/manifest.json` 里有从同一视频切出的每段叫声（`id`、`label`、`text`、`start`/`end` 秒数，`file` 非空的是桌宠在用的）。对 manifest 里**每一段**（含 `file` 为 null 的），在视频对应起止时间内抽 2～4 帧，拼图放 `docs/research/usagi-表情动作/voice/<id>.png`；README 里一张表：`id` → 叫声文字/label → 当时乌萨奇的眼、嘴、眉形状 → 身体动作 → 画面是否看得清（不是乌萨奇或看不清就写明）。最后按 label（ha/ura/yaha/pururu/other…）归纳"这类叫声配什么脸"。
5. **五官特写**：从 GIF 和视频里为每一种不同的五官形态各挑 1～2 帧最清楚的正脸，裁出脸部（眼+嘴，放大到宽 400px 左右），按形态命名放 `docs/research/usagi-表情动作/face/<形态>-<来源>-<帧号或秒>.png`，并拼一张总览 `face/overview.png`；同时把我们现有的五官图集 `assets/model/face/atlas_preview.png` 复制一份进同目录对照，README 里逐个说现有图集格子和参考差在哪（形状、粗细、位置、缺了哪种形态）。主导会据此重画五官图集。
6. 只看画面得出的判断写"推断"，不确定的写"看不清"，不要编。
