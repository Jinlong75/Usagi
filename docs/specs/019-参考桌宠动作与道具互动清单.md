## 要求

写 `docs/research/参考桌宠动作清单.md`：

1. **动作总表**：参考项目里**每一段**动作（每个素材/清单条目一行）：名称原文、所属分类（idle/turn/move/click/drag/random/时间/事件…）、触发条件（随机权重、时段、事件、点击、喂文件……，写源码 文件:行）、时长、是否涉及**道具/物品**（什么道具、和道具怎么互动）、是否配叫声/台词/气泡（台词原文）。素材是视频没法看画面的，按文件名和代码推断并标"推断"。
2. **时间/作息相关**：所有按时钟触发的行为（吃早/午/晚餐、睡觉、起床、报时、问候、节日、每日一签……）：时段边界、触发频率与去重（一天一次？）、全屏/免打扰时怎么处理、用户离开回来怎么处理，写源码位置。
3. **道具互动归类**：把涉及道具的动作归成几类（吃喝、运动如跳绳、玩具、天气/季节如落叶堆雪人、睡觉用品……），每类说参考里怎么表现。
4. **给 Usagi 3D 的选型建议**：我们是 3D VRM + 程序化动作（不能播视频），道具只能用 three.js 简单几何体或小模型做。按"做起来便宜 / 角色感强 / 用户点名（吃东西、跳绳）"给一份推荐清单（15～25 个），每个写：动作要点（身体、手、耳朵怎么动，大致时长）、需要的道具（形状描述）、需要的五官（例如吃东西张嘴、睡觉闭眼）、触发方式（随机/时段/点击/右键菜单喂食）。乌萨奇角色特点（蹦跳、"呀哈""乌拉""哈？"、爱吃）优先。
5. 只看代码推断的写"推断"，没找到的写"没找到"，不要编。
