## 目标

用户 2026-11-17："模型的手和脚都不会动，手脚应该也要能动。"

030 调研（`docs/research/030-骨骼蒙皮/README.md` 的"手脚动作表"与"走路幅度单列"两节，开工先读）结论：蒙皮跟随没问题，是**动作设计**的问题——很多动作只移动/缩放整个角色；Hand/Foot 从不驱动；走路摆臂只有 ±0.025 rad 且接近绕手臂长轴扭转，200 px 高时手端只动约 0.16 px。

依赖：027、028（都改 `app/src/renderer/index.ts` / `motion/index.ts`）和 031（臂根权重修好后，抬手才不会把头侧扯皱）。开工先读这三个合入后的代码。

## 主导定的动作（正面视角为准，桌宠平时就是正面）

短手臂静止时沿 ±X 伸出，**绕 Z 旋转 = 手上下扇动（正面看得见）**，绕 X 主要是扭动（正面几乎看不见）。下面角度都是 VRM normalized 局部旋转（rad），左右按现有代码的符号约定镜像。

| 动作 | 手 | 脚 | 要点 |
|---|---|---|---|
| walk | 上臂绕 Z 左右**交替**上下摆，幅度 0.25，与步伐同相（左脚抬时右手抬）；去掉原来绕 X 的 ±0.025 | 抬腿：大腿 X 0.35、小腿 X 0.30 交替，抬起的那只脚 Foot X −0.2 让脚尖下垂；落地脚伸直 | 小碎步，蹦蹦跳跳的感觉；根部弹跳、侧倾保留原值 |
| jump / happy | 起跳前蹲时两手下压（Z 往下 0.15），腾空时两手举起（Z 往上 0.45，前臂 0.15），落地回原位 | 腾空时两腿微收（大腿 X 0.25、小腿 X 0.35），落地伸直 | 跟随现有 `jumps()` 的相位，不改跳跃高度和时长 |
| eatRiceball / eatWatermelon / iceCream / sneakSnack | 保持现在抬手 0.2，**每一口**时两手再往上 0.12（0.25 s 内起落），咀嚼时随咀嚼小幅 ±0.04 | 不动 | 手跟着咬的节奏动；道具位置不改（029 刚改过西瓜） |
| jumpRope | 原来同相绕 X ±0.06 改为绕 Z 的画圈：Z 0.18 + 0.10·sin，X 0.10·cos（两手同相，跟绳子周期） | 每次跳过绳时两腿微收（同 jump 腾空） | 不改绳子和道具 |
| idle / lookAround | 每 3.5 s 周期里手随呼吸 Z ±0.04 轻摆 | 不动 | 很轻，只是"活着"的感觉 |
| shake / surprised | surprised：两手瞬间上扬 Z 0.35 后回落；shake：不加 | 不动 | |
| drag（被拖着） | 保留现有；另加两腿随速度前后晃（大腿 X ±0.15·v） | 同左 | |

- `MotionRig` 的 `BONES` 复位名单加入 `leftHand/rightHand/leftFoot/rightFoot`，切换动作时不残留。
- 角度表放在 `motion/index.ts` 顶部的一个常量对象里（例如 `LIMB`），方便主导之后微调。
- 抬手最大角不得超过 stretch 现有的 0.43 + 前臂 0.10（031 的权重检查以此为上限）。

## 验收

- 新测试 `app/tests/limb-motion.test.ts`：用真实 `assets/models/usagi.vrm`、three-vrm CPU 蒙皮（参照 030 的方法），按 200 px 模型高度换算正面屏幕投影：
  - walk 一个完整步伐周期里，左右手端各自的正面投影位移峰峰值 ≥ 3 px，左右脚端各自 ≥ 3 px（扣除整体根部平移、弹跳、侧倾，只算肢体相对身体的位移）；
  - jump 腾空峰值帧手端比起跳前高 ≥ 4 px；
  - 每个动作结束回到 idle 后，所有四肢骨骼旋转回到 0（≤ 1e-6）。
- 冒烟截图（门禁产物）加：walk 抬左脚帧、walk 抬右脚帧、jump 腾空帧、eatRiceball 咬一口帧。主导看图验收手脚动作，**截图里头侧不应有皱褶、手上方不应有尖角**（若出现，汇报里写出是哪一帧，不要自己改权重）。
