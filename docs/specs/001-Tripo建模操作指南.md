## 目标

写一份中文操作指南 `docs/guides/01-Tripo建模.md`，让不熟悉 3D 的用户照着做，就能得到一个可以继续做 VRM 的 Usagi 3D 模型（.glb），并放到 `Material/tripo/usagi_tripo.glb`。

## 范围 / 不做什么

- 只写指南文档，不调用任何 API，不生成图片或模型。
- 不写 Blender、骨骼、VRM 的内容（后续步骤由脚本做）。

## 参照

- 用户需求：`usagi3Dpet.md` 第 1 步（"tripo 生成 3D 模型：生成 usagi 的 T-pose 多视图，使用 tripo 的智能拓扑网格生成智能网格"）。
- 项目目标与已定方案：`.agent-router/target.md`，特别是 **D3：模型不要五官**（眼睛、嘴、腮红后面用贴片做表情，所以 Tripo 生成的身体脸上要是干净的底色）。
- 角色参考图：`Material/` 下的 GIF。比较清楚的正脸参考：`Material/a694b860e187ac78192c5f0e502fad2a1942011.gif`、`Material/7f1ef01d996e7adba46e30f233abd61f1942011.gif`（自己再挑 1～2 张能看到全身或侧面的，写进指南）。
- 角色特征：奶黄色圆滚滚的 Q 版兔子，头身几乎一体；头顶两只细长直立的耳朵，耳朵内侧粉色；短小的手脚；白色圆尾巴；描边是深棕色细线。

## 验收标准

指南按下面的小节写，标题照抄：

1. `## 准备`：需要什么账号（Tripo 网页 tripo3d.ai）、大概花多少积分（查不到准确数字就写"以网页显示为准"）、要用到的参考图文件名。
2. `## 第一步 生成 T-pose 多视图图片`：
   - 说明为什么要 T-pose（双臂水平张开、双腿略分开，方便后面绑骨骼）和为什么要**无五官**（脸上只留底色，不画眼睛、嘴、腮红；耳朵内侧的粉色保留）。
   - 给出可直接复制的图片生成提示词，中文、英文各一份；要求：纯白背景、正交视角、无阴影、无描边或极细描边、同一角色的正面 / 左侧 / 背面 / 右侧四张（或 Tripo 多视图要求的视图组合）、全身完整入画、耳朵完整不被裁切。
   - 说明可以用哪些工具出图（Tripo 网页自带的生图或多视图功能如果有就优先；也可以用其他 AI 生图工具），以及怎样把参考 GIF 截一帧当参考图上传。
   - 出图检查清单：四张图角色比例一致、耳朵位置一致、没有五官、背景纯白、手臂水平。
3. `## 第二步 Tripo 多视图生成模型`：在 Tripo 网页上的操作顺序（上传多视图、选择智能拓扑 / 智能网格 Smart Mesh 一类选项、面数建议 1 万～2 万面、开启贴图、不要使用 Tripo 自带的自动绑骨）。网页上按钮的确切名称不确定的，写成"类似『……』的选项"，并在文档末尾 `## 待确认` 列出。
4. `## 第三步 导出与放置`：导出 GLB 格式（带贴图），文件改名并放到 `Material/tripo/usagi_tripo.glb`；同时把第一步用到的四张多视图图片放到 `Material/tripo/views/`。
5. `## 交付检查`：放好后用户自己能核对的清单（文件在不在、在 Tripo 预览里是否 T-pose、脸上是否无五官、耳朵是否完整、大概面数），以及"放好后告诉主导，主导会跑清理脚本"。
6. `## 常见问题`：至少写耳朵粘连 / 断掉、手臂和身体粘在一起、脸上出现五官、背面贴图糊这几种情况怎么重新生成。
7. `## 待确认`：所有不确定的网页按钮名、积分数字，没有就写"无"。

全文中文，面向非专业用户，句子直白；不编造确切数字或按钮名，不确定就写进 `## 待确认`。
