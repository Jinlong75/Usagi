## 目标

把 007 做好的聊天核心和 006 做好的行为系统接到界面上：桌宠头顶会冒气泡、自言自语；右键或托盘能打开聊天窗口和 DeepSeek 设置页；用户填好 Key 就能和 Usagi 聊天，Usagi 回复时桌宠做对应表情、冒气泡、偶尔叫一声。

## 范围 / 不做什么

- 做：气泡窗口、自言自语、聊天窗口、设置页、右键菜单与托盘菜单补项、鼠标穿透开关、IPC 接线、配置字段、情绪→表情联动、冒烟扩展、测试。
- 不做：改 `app/src/main/chat/**` 的核心逻辑（只调用它；发现核心缺陷写进汇报 `TODO(lead)`）；会话列表/多会话、Markdown 渲染、记忆、余额、看屏幕、开机自启、打包（后续任务）。
- 不加新的 npm 依赖。

## 要求

### 1. 配置（`app/src/main/config.ts`，主进程唯一持有，改动广播给各窗口）
新增字段与默认值（旧配置文件缺字段时补默认，测试覆盖）：
- `chat`: `{ baseUrl: 'https://api.deepseek.com', model: 'deepseek-flash', temperature: 0.7, maxTokens: 2048, thinking: 'disabled' }`
- `selfTalk`: `{ enabled: true, minSec: 20, maxSec: 60, lines: [] }`（`minSec` 下限 5；`lines` 为空时用内置台词）
- `volume`: `0.7`（0～1）
- `mousePassthrough`: `false`
- API Key **不进** config.json，只走 keyStore。

### 2. 气泡窗口（`app/src/bubble/` + `app/src/main/windows/bubble.ts`）
- 独立的透明、无边框、置顶、**完全鼠标穿透**、不抢焦点（`focusable:false`、`showInactive()`）小窗口，跟随桌宠窗口移动，显示在桌宠头顶上方水平居中；上方空间不足时放到桌宠左侧或右侧（哪边空间大放哪边）。
- 样式：白底圆角、深棕色 2px 描边（和 Usagi 描边同色 `#4A2A1A` 左右）、小尾巴指向桌宠、字号 14px、最大宽 240px 自动换行、淡入淡出 150ms。文字一律用 `textContent`，不渲染 HTML。
- `showBubble(text, durationMs)`：新气泡替换旧气泡；默认显示 3.2 秒。

### 3. 自言自语（`app/src/main/selfTalk.ts`）
- 开启时每隔 `[minSec, maxSec]` 均匀随机的时间冒一句；下一次延迟 = 随机间隔 + 显示时长。
- 内置台词（`lines` 为空时用，下面全文照抄）：`呀哈！`、`乌拉！`、`哈？`、`噗噜噜噜噜……`、`呀哈呀哈！`、`乌拉～乌拉～`、`哈啊？！`、`咿呀～哈～！`、`嗯～？`、`呀——哈——！`。只排除上一句。
- 30% 概率同时播一段 `idle_talk` 叫声（音量取配置）。
- 跳过条件：桌宠隐藏、正在拖动、聊天请求进行中、气泡正被聊天占用；跳过后按正常间隔重排。
- 计时与选句写成纯函数，注入随机与时钟，单测覆盖。

### 4. 右键菜单与托盘
- 在桌宠身上右键弹出菜单（`Menu.popup`），托盘菜单同步补项。菜单项（中文）：`和乌萨奇聊天`、`设置…`、`自言自语`（勾选）、`鼠标穿透`（勾选）、`始终置顶`（勾选，已有）、`大小 ▸ 小/中/大`（已有）、`显示/隐藏`、`退出`。
- 开启鼠标穿透时：桌宠窗口整窗 `setIgnoreMouseEvents(true)`（不 forward），并冒气泡 `已开启鼠标穿透，在菜单栏图标里可以关掉哦` 4 秒；只能从托盘关闭。

### 5. 聊天窗口（`app/src/chat-window/` + `app/src/main/windows/chat.ts`）
- 普通窗口（有阴影、可调大小、无系统标题栏也可以但要能拖动），默认 360×520，首次打开放在桌宠旁边不遮挡桌宠且不出屏幕；关闭只隐藏，记住位置。
- 顶部：标题 `乌萨奇`、状态文字（`就绪` / `正在想…` / `回复中…` / `出错了`）、`清空对话` 按钮（二次确认）。
- 中间：消息列表（用户靠右、Usagi 靠左，Usagi 消息前显示情绪对应的小表情符号：开心 😆、惊讶 😮、生气 😤、难过 🥺、平静 🙂），自动滚到底；打开时加载已保存的会话。
- 底部：多行输入框，`Enter` 发送、`Shift+Enter` 换行；请求进行中按钮变 `停止`。
- 流式显示：打字机效果，每 16ms 取 `max(1, min(10, ceil(待显示长度/40)))` 个字符。
- 错误：在消息列表里显示一条红色系统消息（文案来自 ChatError.message）；`no_key` 时附一个 `去设置` 按钮。

### 6. 设置页（`app/src/settings/` + `app/src/main/windows/settings.ts`）
单页，**关闭即保存并立即生效**（同时有 `保存` 按钮）。分三组：
- **AI 对话**：API Key（密码框，显示掩码 `sk-****abcd`，`显示` 切换；保存后若 `persisted:false` 在框下方红字显示 keyStore 返回的原因）、`测试连接` 按钮（显示 `连接成功，可用模型：…` 或错误文案）、模型（下拉：`deepseek-flash`（默认，快且便宜）、`deepseek-v4-pro`（更聪明）、`自定义…` 文本框）、API 地址（高级，可折叠）、温度（0～1.5 滑块）、深度思考（开/关）、一行说明 `Key 在 platform.deepseek.com 创建，只保存在本机并加密。`
- **桌宠**：自言自语开关、间隔最短/最长秒数、自定义台词（多行文本框，每行一句，空则用内置）、音量滑块。
- **关于**：版本号、`素材来自《Chiikawa》，仅供个人使用。`

### 7. 聊天与桌宠联动
- 发送后：气泡 `嗯……让我想想` 直到首个正文片段到达；回复中：气泡显示回复前 60 字（随流式更新，节流 200ms）；完成：气泡显示完整回复前 60 字（超出加 `…`）5 秒，并按情绪让桌宠做 2 秒表情（开心→`happy`、惊讶→`surprised`、生气→`angry`、难过→`sad`、平静→不变），50% 概率播一段 `chat_reply` 叫声；出错：气泡显示错误文案前 80 字 4 秒。
- 表情由主进程发事件给桌宠渲染进程，渲染进程调用 006 行为系统已有的表情接口（没有现成接口就在 renderer 里加一个，不改动作逻辑）。

### 8. 退出与安全
- `before-quit` 时等待 `sessionStore.flush()`（最多 2 秒）再退出。
- 所有窗口 `contextIsolation:true`、`nodeIntegration:false`、`sandbox:true`；preload 只暴露各窗口需要的最小接口；IPC 校验发送方。
- 日志不出现 API Key。

### 9. 测试与冒烟
- 单测：配置默认值合并与迁移、自言自语计时与选句、气泡位置计算（上方/左/右三种）、打字机取字数、情绪→表情映射、菜单状态与配置同步。
- 冒烟（扩展 `app/scripts/smoke.mjs`）：在冒烟模式下用**假的 ChatService**（不联网）跑一轮：显示气泡 → 打开聊天窗口发送一句 → 假服务流式返回 `[开心]呀哈！今天也要元气满满！` → 完成。截图：`smoke-bubble.png`（桌宠+气泡）、`smoke-chat.png`（聊天窗口，含用户消息与 Usagi 回复）、`smoke-settings.png`（设置页），写到 `AR_GATE_ARTIFACT_DIR`。输出 JSON 增加 `"ui": ["bubble","chat","settings"]`。原有截图与检查保留。
